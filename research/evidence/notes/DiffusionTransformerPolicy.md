# DiffusionTransformerPolicy — Diffusion Transformer Policy (2024, arXiv 2410.15959)
Setup: Generalist policy: frozen CLIP text encoder + DINOv2-B (fine-tuned, 224x224) + Q-Former (FiLM on text) → 12-layer Llama2-style causal transformer (hidden 768) that DENOISES the action chunk in-context (noisy action tokens concatenated after image/text/timestep tokens). 334M params total, 221M trained. Actions: 7-D EE (Δtrans, Δrot, gripper). OXE pretraining (DDPM T=1000; 100k steps; batch 8,192-ish; 2 obs images, 32-step chunks). Evaluations: SimplerEnv (Google robot), CALVIN ABC→D (single static RGB, 10-step chunk), LIBERO (fine-tune), ManiSkill2 (5 tasks, ~40K trajectories rendered from 20 random cameras each, from scratch, 500 eval trajectories), real Franka with single third-person RGB camera 1.5 m away, black background, small objects; 9-grid object positions (27 trials/task inferred from 7.4% = 2/27). Real fine-tuning with LoRA, DDPM 100 steps.
Claim: using the whole transformer as the denoiser (in-context conditioning on image patches) beats both discretized action heads (RT-1/OpenVLA-style 256 bins) and small MLP diffusion heads (Octo-style) conditioned on a single embedding.
Evidence (head comparisons with same backbone/encoders):
 - ManiSkill2, novel-camera generalization, from scratch (Table 4, All / PickCube / StackCube / SingleYCB / ClutterYCB / EGAD): Discretized head 30.2 / 41 / 33 / 22 / 1 / 54; Diffusion MLP head 58.6 / 86 / 76 / 37 / 24 / 70; DiT Policy 65.8 / 79 / 80 / 62 / 36 / 72.
 - Real Franka in-domain, 50 demos per trained task (Table 6, All / Block / Banana / Kiwi / Tiny(unseen) / Oval(unseen)): Discretized 19.3 / 29.6 / 51.9 / 14.8 / 0 / 0; Diffusion MLP head 34.8 / 40.7 / 85.2 / 25.9 / 22.2 / 0; DiT 46.9 / 55.6 / 90.3 / 44.4 / 37.0 / 7.4.
 - CALVIN ABC→D avg length (Table 2): diffusion head w/o pretrain 1.68, diffusion head 3.16, DiT w/o pretrain 2.38, DiT 3.61 → OXE pretraining +1.23; DiT vs MLP-head +0.45 (pretrained) / +0.70 (scratch).
 - Real 10-shot fine-tune (Table 5; Octo / OpenVLA / DiT): PickBlock 7.4 / 7.4 / 14.8; PickBanana 22.2 / 33.3 / 33.3; Pourballs 14.8 / 18.5 / 29.6; Pick&Insert step-1 20 / 80 / 90, step-2 0 / 0 / 10; Stacking bowls step-2 0 / 0 / 12. (Absolute numbers low for everyone at 10 demos.)
 - LIBERO avg (Table 3): DP from scratch 72.4, Octo 75.1, OpenVLA 76.5, DiT 82.4 (LIBERO-Long 50.5 / 51.1 / 53.7 / 63.8). SimplerEnv (Table 1): e.g. coke can match 72.7 vs RT-1-X 56.7 / OpenVLA 16.3 / Octo 17.0.
Ablations (ManiSkill2, Table 7/8):
 - trajectory length (obs+pred) with 2 obs: 2 → 40.8, 4 → 51.6, 8 → 62.4, 16 → 65.6, 32 → 65.8 (ClutterYCB 9 → 36).
 - # obs: 1 obs/32 → 61.6 vs 2 obs/32 → 65.8; 3 obs/3 → 35.4 (more history tokens hurt convergence).
 - execution steps per inference (chunk 32): 1 → 61.6, 2 → 60.8, 4 → 60.6, 8 → 60.0, 16 → 58.0 (short execution slightly better).
 - larger MLP head does not close the gap (stated); "Diffusion head with action chunks [Octo]" poor on ManiSkill2 (stated).
Failure/limitations: limitation sentence truncated in extraction. Critical read: head and conditioning style are confounded (DiT = bigger denoiser + direct patch conditioning); real trials ~27 per task, single scene, single camera, black background; DDPM 100 steps — NO latency numbers given anywhere despite 334M model with 100 denoising passes (would be slow on an 8 GB laptop); failures in real are "tiny position bias" in grasps. Discretized baseline uses per-dim 256 bins whose statistics were computed from 10 demos — authors note discretization is sensitive to normalization statistics in few-shot.
Conflicts: agrees with Dita (in-context DiT denoiser > MLP diffusion head) — same author group; opposite to OpenVLA-OFT/ACT-style regression success — no regression baseline here. Supports DP/ACT finding that longer chunks help (up to ~16–32 steps) and short execution is slightly better.
Relevance: Two useful signals for SO-101: (1) with 50 real demos per task and a pretrained backbone, continuous diffusion heads beat per-dimension discretized tokens by ~15–27 pts (46.9/34.8 vs 19.3) — avoid naive binning of joint actions; (2) a big transformer denoiser run 100 steps is the wrong latency profile for us; if we use transformer-as-denoiser, pair with flow matching and ≤10 steps. Novel-view generalization in ManiSkill2 required 40K trajectories × 20 cameras — not reproducible at our scale.
Decision impact:
 - Q01 action head: per-dimension discretized tokens — WEAKENED (real 19.3 vs 34.8/46.9; ManiSkill2 30.2 vs 58.6/65.8) — confidence M (same backbone, ~27 real trials/task).
 - Q01 action head: denoiser capacity/conditioning matters — full-transformer in-context denoiser > small MLP head (+12 real pts, +7 ManiSkill2, +0.45 CALVIN) — confidence M.
 - Q06 chunking: prediction length 2 → 32 raises ManiSkill2 40.8 → 65.8; exec steps 1 vs 16: 61.6 vs 58.0 — confidence M.
 - Q07 history: 2 obs > 1 obs for long chunks (+4.2); 3 obs hurt (35.4) — confidence L/M.
 - Q12 model size: 221M trained params OK with 50 demos only thanks to OXE pretraining (CALVIN +1.23 from pretraining) — confidence L/M.
