# VQ-BeT — Behavior Generation with Latent Actions (2024, arXiv 2403.03181, ICML)
Setup: 7 sim envs (PushT state+image, Kitchen state+image, BlockPush, UR3 BlockPush, Multimodal Ant) + nuScenes planning + REAL Hello Robot Stretch (low-cost mobile manipulator, Dobb·E-style handheld-stick data, ego/wrist camera only, HPR encoder fine-tuned; 5 single-phase + 3 two-phase + 4 long-horizon tasks; 10 trials per task). Demo counts for real tasks: not in extracted text (appendix missing). Residual VQ-VAE (Nq=2 layers) tokenizes action (or chunk) → MinGPT predicts primary/secondary codes (focal loss, secondary weight β) + continuous offset head. Single forward pass.
Claim: learned residual-VQ action tokens + offset give multimodal, fast (single-pass) behaviour generation that matches/beats Diffusion Policy while being 5× (sim) – 25× (real) faster.
Evidence:
 - Unconditional sim (Table 2; BC / BeT / DP-C / DP-T / VQ-BeT): PushT final IoU .65/.39/.73/.74/.78; Image PushT .13/.01/.66/.45/.68; Kitchen goals(/4) .18/3.07/2.62/3.44/3.66; Image Kitchen .75/2.48/3.11/3.01/2.98; Ant(/4) .01/2.73/3.12/2.90/3.22. DP-T wins BlockPush, DP-C wins Image Kitchen (other cells ambiguous in extraction; not cited).
 - Goal-conditioned (Table 1; GCBC / C-BeT / C-BESO / CFG-BESO / VQ-BeT): Kitchen 0.15/3.09/3.75/3.47/3.78; Image Kitchen 0.64/2.41/2.00/1.59/2.60; PushT .02/.02/.30/.25/.39.
 - Real Stretch single-phase (Table 5, total /50): VQ-BeT 47, DP-T† 45, BC w/ depth 27, BC 29. Two-phase (/30): VQ-BeT 19, DP-T† 11, BC-depth 4, BC 7 ("+73% relative"). Long-horizon (Table 6) end-of-task: e.g. Task 4 VQ-BeT 6/10 vs DP-T 1/10; Task 2 6/10 vs 2/10; early subtasks similar (Task 1 approach 8 vs 10).
 - Latency, Kitchen sim (Table 3): VQ-BeT 15 ms, BeT 13 ms, DP-C 100 ms, DP-T 99 ms (DP at 10 denoising iterations). Real robot (Table 7) GPU A4000: VQ-BeT 18 ms, DP-T 573 ms, BC 4.7 ms; onboard 4-core CPU: 207 ms vs 5,244 ms vs 83 ms.
Ablations (Fig. 5, conditional Kitchen / Ant / nuScenes; figure only, qualitative): vanilla single VQ layer → significant drop; β=1 (equal code weights) → drop; no offset → drop ("full action fidelity important"); autoregressive code prediction → drop in Kitchen sim but reported IMPORTANT on real robot; ACTION CHUNKING → "performance lacking" for VQ-BeT (it's used single-step, closed loop).
Failure/limitations: authors: receding-horizon (open-loop chunk) execution "fails completely" on the imprecise Stretch — controller noise pushes policy OOD within 3 open-loop steps, so all policies run fully closed-loop (Table 11 in appendix not extracted). Critical read: DP-T was run closed-loop single-step (modified "†"), which is not DP's designed regime (chunked, receding horizon) and inflates DP latency (573 ms); 10 trials/task; real tasks mostly single-mode by authors' own statement for single-phase; no demo counts visible; no robustness (lighting/camera) evals. Real advantage appears mainly on long horizon (compounding), which could be a history/closed-loop effect as much as a head effect.
Conflicts: VQ-BeT says chunking hurt it and open-loop chunks fail on cheap hardware; ACT/DP/RTC find chunking essential. Why: VQ-BeT runs 1-step closed-loop at high re-query rate with a tiny fast model; chunk tokenization with a 2-layer RVQ may lack fidelity for long chunks. ACT uses chunks WITH temporal ensembling/closed-loop re-query, which also addresses controller noise. The "DP fails on cheap hardware" finding is relevant to SO-101 backlash but was for executing 3+ steps open-loop without ensembling.
Relevance: SO-101 is also a low-cost imprecise arm → take the warning seriously: do not execute long open-loop chunks; re-query often (or RTC-style). A single-pass tokenized head is attractive for 8 GB laptop latency (18 ms vs 573 ms). But VQ-BeT's gains over DP on simple single-phase real tasks are marginal (47 vs 45/50); pumpkin-to-tray is single-phase.
Decision impact:
 - Q01 action head: discrete residual-VQ tokens ≈ diffusion on simple real tasks (47 vs 45/50), better on multi-phase (19 vs 11/30) — supports VQ/tokens as viable — confidence L/M (DP handicapped closed-loop, 10 trials).
 - Q01 action head: plain MLP-BC on real single-phase 29/50 vs generative ~46/50 — weakens regression (MLP, no chunking) — confidence M.
 - Q06 chunking: open-loop chunks fail on low-cost imprecise robot; VQ-BeT with chunks worse — weakens long open-loop execution — confidence M (strong statement, table not visible).
 - Q10 latency: single-pass 18 ms vs DP 573 ms closed-loop (GPU), 25× — supports single-pass/few-step heads — confidence M/H.
