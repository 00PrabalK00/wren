# CogACT — CogACT: A Foundational Vision-Language-Action Model for Synergizing Cognition and Action in Robotic Manipulation (2024, arXiv 2411.19650)
Setup: Prismatic/OpenVLA-initialized 7B VLM (DINOv2+SigLIP → 256 visual tokens, Llama-2) outputs a single "cognition token" feature that conditions a separate diffusion transformer action module (default DiT-Base 89M; 7.6B total). Predicts current + N=15 future 7-D delta-EEF actions (chunk 16); DDPM noise-MSE loss, all modules trained end-to-end. Inference: Adaptive Action Ensemble — cosine-similarity-weighted average of the current and K past predictions for step t (α=0.1; K=2 Google robot, K=7 WidowX, set from action std/motion speed). Pretrain: OXE subset (22.5M frames), batch 256, 8 diffusion samples per example, LR 2e-5 const, 135K iters, 16 A100 × ~5 days (FSDP). Eval: SIMPLER Google robot (Visual Matching VM / Variant Aggregation VA) and WidowX VM; real Realman 7-DoF arm (391 demos total, 48/67/79 for eval tasks, some specific variants only 2 demos; 24–48 trials/task) and Franka (100 demos × 4 tasks, 11 trials/task).
Claim: separating cognition (VLM) from action (DiT) with a sizeable diffusion action module beats discrete-token VLAs (OpenVLA +59.1% real) and scales with action-module size.
Evidence:
 - SIMPLER Google VM avg (Table 1): RT-1 52.4, RT-1-X 42.4, RT-2-X 46.3, Octo-Base 11.0, OpenVLA 34.3, CogACT 74.8. VA avg: RT-1 43.7, RT-1-X 30.2, RT-2-X 54.4, Octo-Base 1.2, OpenVLA 39.3, CogACT 61.3.
 - SIMPLER WidowX VM avg: CogACT 51.3 (others lower; per-baseline numbers not cleanly extractable).
 - Realman fine-tune (Table 3, all OXE-pretrained then fine-tuned): task avg Octo-Base 4.9, OpenVLA 12.1, CogACT 71.2 (Pick 8.3/8.3/70.8; Stack 0.0/15.6/82.3; Place 6.3/12.5/60.4).
 - Realman OOD (Table 4, unseen tables + unseen distractors): OpenVLA 9.7 vs CogACT 58.4 (drop from 71.2). Table 5 unseen colors 0.0 vs 87.5, shapes 6.3 vs 81.3, categories 12.5 vs 25.0, avg 6.3 vs 64.6.
 - Franka (Table 6, 100 demos/task, 11 trials): avg Octo-Base 5.8, OpenVLA 6.8, CogACT 61.4.
Ablations (SIMPLER; columns GR-VM / GR-VA / WR-VM / avg):
 - Action module (Table 7): MLP-3L (3M) 52.2/52.4/47.1/50.6; MLP-7L (89M) 61.4/48.0/48.1/52.5; DiT-S (13M) 73.3/51.3/51.0/58.5; DiT-B (89M) 74.8/61.3/51.3/62.5; DiT-L (308M) 76.7/59.3/58.3/64.8. → at equal params (89M) DiT > MLP by +10 avg; a 13M DiT already beats an 89M MLP; gains ~log-linear in size.
 - Future steps predicted (Table 8): N=0 → 73.4/49.0/6.3/42.8; N=3 → 70.4/58.9/37.1/55.5; N=15 → 74.8/61.3/51.3/62.5; N=31 → 54.3/47.6/51.7/51.2. Too long a chunk hurts (Google robot, 3 Hz data: 32 steps ≈ 10 s); single-step collapses on WidowX (6.3).
 - Execution strategy (Table 9, same prediction model): Action chunking (execute first 2 open-loop) 67.4/52.5/32.1/50.7; ACT temporal ensemble 75.0/59.9/41.9/58.9; adaptive ensemble 74.8/61.3/51.3/62.5.
Failure/limitations: Critical read: ablations are sim-only (SIMPLER), with VM/VA mixing; the action-module size effect is confounded with a 7B backbone (the DiT is conditioned on one cognition token). Baselines fine-tuned by the authors — Octo-Base ~5% on real tasks suggests an untuned recipe (Octo's own paper reports 50–100% with ~100 demos). Realman fine-tune data is multi-task (391 demos), so per-task demo counts are tiny; eval 8 trials/object. "Action chunking" baseline executes only 2 steps, so it is not ACT-style long open-loop chunks. Training/inference compute (16 A100; 7.6B model) not 8 GB compatible; no latency reported in main text.
Conflicts: Temporal ensembling helps here (+8 avg over 2-step chunking) while Octo found no benefit over receding horizon — CogACT's ensemble uses the diffusion model's multimodal predictions and similarity weighting; Octo's evaluations were fewer. Multi-step prediction sweet spot at 16 (≈5 s at 3 Hz on RT-1 data, ≈3 s at 5 Hz Bridge) resembles ACT/DP findings that overly long chunks hurt reactivity. Separate diffusion action module > token head agrees with OFT, Octo, RDT (continuous > discrete).
Relevance: The 7B model is out of reach, but the ablations transfer: (1) a transformer-based diffusion action head of ~13–90M beats MLP heads of equal/larger size — relevant for designing our small head; (2) chunk horizon should cover ~1–3 s, not longer; (3) similarity-weighted temporal ensembling of overlapping chunks is a cheap, training-free smoother that also improves success — directly relevant to our jerky chunk-boundary problem (though it requires running inference every step or every few steps, so latency must be low).
Decision impact:
 - Q01 action head: DiT diffusion head > MLP head at equal params (62.5 vs 52.5 avg) — confidence M (sim only, 7B conditioning).
 - Q06 chunking: predict 16 steps best; 32 drops 62.5→51.2; single-step 42.8 — confidence M.
 - Q10 smoothness: adaptive ensemble 62.5 vs temporal ensemble 58.9 vs 2-step chunk execution 50.7 — supports overlapping-chunk ensembling for smooth boundaries — confidence M (sim).
 - Q12 model size: action module 13M→89M→308M: 58.5→62.5→64.8 (log-linear) — confidence L/M (backbone fixed 7B).
 - Q14 robustness: unseen table+distractors 71.2→58.4; unseen colors/shapes 81–88%, categories 25% — VLM-pretrained backbone generalizes color/shape, not category — confidence L/M (8–16 trials).
