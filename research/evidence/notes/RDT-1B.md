# RDT-1B — RDT-1B: A Diffusion Foundation Model for Bimanual Manipulation (2024, arXiv 2410.07864, ICLR 2025)
Setup: 1.2B DiT (28 layers, hidden 2048, 32 heads) denoising an action chunk Ta=64 conditioned via cross-attention on FROZEN SigLIP image tokens (3 views: exterior + 2 wrist, 2-frame history, 384x384) and FROZEN T5-XXL language tokens (alternating image/lang injection per layer); proprio + noisy chunk + control frequency + diffusion step as input tokens (Fourier-feature MLPs); QKNorm + RMSNorm; nonlinear MLP decoder. 128-D "physically interpretable unified action space" (units kept physical, not normalized; padding mask vector). Pretrain: 46 datasets, 1M+ traj (21 TB), 48 H100 × 1 month, 1M steps. Fine-tune: own 6K+ episode, 300+ task Agilex Cobot Mobile ALOHA dataset (3 cams, joint pos), 130K steps on 48 H100 (3 days) — from the 500K checkpoint. DDPM 1000 steps train, DPM-Solver++ 5 steps inference: 6 Hz chunks / 381 actions/s on onboard RTX 4090. Aug: color jitter, image corruption, proprio Gaussian noise (40 dB SNR), GPT-4 instruction rewriting, 10% independent modality masking. Eval: 7 tasks, 8 trials per condition (24 per task) or 25 trials.
Claim: diffusion + large model + multi-robot pretraining yields zero-shot generalization to unseen objects/scenes/instructions and few-shot (1–5 demo) learning of new bimanual skills.
Evidence (Table 3, success %, rows ACT / OpenVLA / Octo / RDT-scratch / RDT):
 - Handover (5-shot, 25 trials) Total: 0 / 0 / 0 / 16 / 40.
 - Fold Shorts (1-shot, 25 trials) Total: 0 / 0 / 4 / 40 / 68.
 - Robot Dog (dexterity, 68 demos, 25 trials) Total: 32 / 0 / 4 / 64 / 76; Walk Straight 32 / 0 / 0 / 32 / 48.
 - Wash Cup / Pour Water tables are scrambled in extraction; authors state RDT on unseen cups/rooms is "not much different" from seen, baselines fail to complete full tasks.
Ablations (Table 2; Wash Cup unseen cup 2 / Pour Water unseen room 3 / Pour-L-1/3 correct amount; 8 trials each):
 - RDT (regress, deterministic, 1.2B pretrained): 12.5 / 50 / 12.5.
 - RDT (small, 166M, pretrained): 37.5 / 62.5 / 25.
 - RDT (scratch, 1.2B no pretrain): 0 / 25 / 62.5.
 - RDT (full): 50 / 62.5 / 100.
 - Architecture (Fig. 4, no pretraining): without QKNorm+RMSNorm pretraining loss unstable/explodes; without MLP decoder dexterous Robot Dog success drops; without alternating condition injection instruction following degrades (figure only).
 - Design notes: Ta=64 chosen by referring to ACT ablations (not re-ablated); proprio HISTORY deliberately excluded "to prevent shortcuts... sticking to fixed motion patterns"; image history 2 frames; CFG made arm behaviour unstable, not used; sampled-action MSE on train set correlates with deployment success, "overly low MSE may mean overfitting".
Failure/limitations: Critical read: "1-shot / 5-shot" skills are learned inside a 6K-episode, 300-task fine-tuning set of the SAME robot — not few-shot on a new robot. Only 8 trials per ablation cell (12.5% granularity); ablation uses 3 hand-picked sub-metrics. Compute (48 H100) is irreproducible for us. Baselines were weakened: OpenVLA and Octo did not converge on the full fine-tune set, so were fine-tuned per-task (~100 episodes), Octo with chunk 8; ACT trained 8 days on the full set. OFT (see OpenVLA-OFT note) found RDT-1B ignores visual feedback and over-relies on proprio (keeps pouring after missing bowl).
Conflicts: Diffusion ≫ regression at 1.2B (50 vs 12.5 unseen object) contradicts OFT's "L1 ≈ diffusion at 7B" — RDT data is multimodal bimanual human teleop without cleaning; OFT used filtered LIBERO + ALOHA. Small (166M) vs 1.2B: modest gap on scene (62.5 = 62.5) but larger on instruction following (25 vs 100) — model size matters most for language. Agrees with Octo on 2-frame image history and on avoiding proprio shortcuts; disagrees with HPT (proprio helps) — note RDT excludes proprio HISTORY but keeps current proprio.
Relevance: Not trainable on 8 GB (1.2B DiT + T5-XXL + SigLIP; even inference needs a 4090 24 GB). Transferable pieces for a small SO-101 policy: (1) diffusion/flow head over a chunk, not regression; (2) per-modality random masking (10%) so the policy doesn't ignore the wrist camera; (3) photometric aug + proprio noise against overfitting; (4) drop the static start of each episode; (5) 5-step DPM-Solver++ sampling gives large chunks cheaply; (6) lighting diversity collected into the fine-tuning data (colour-changing lights). The 166M "small" variant is the only size data point near our budget, and it was pretrained.
Decision impact:
 - Q01 action head: diffusion vs regression 50 vs 12.5 (unseen object), 100 vs 12.5 (instruction) — supports diffusion — confidence M (8 trials, 1.2B scale).
 - Q06 chunking: Ta=64 at ~25–30 Hz ALOHA, with 5-step solver — supports long chunks with fast samplers — confidence L (not ablated).
 - Q07 history: 2-frame image history, no proprio history to avoid shortcuts — confidence L (design choice, no ablation).
 - Q11 cameras: independent modality masking to avoid over-relying on exterior view vs wrist — confidence L (no ablation).
 - Q12 model size: 166M vs 1.2B: 37.5 vs 50 unseen object, 25 vs 100 instruction — size matters mostly for language — confidence L/M.
 - Q13 data: pretraining critical for OOD (scratch 0 vs 50 unseen object, 25 vs 62.5 unseen scene) — confidence M.
 - Q05 augmentation: color jitter + corruption + proprio noise used against fine-tune overfitting — confidence L (no ablation).
