# W4_ArtificialFoveatedPerceptionforMitigatin — Artificial Foveated Perception for Mitigating Shortcut Learning in Robotic Foundation Models (2026, CoRL 2026; arXiv id not in text)
Setup: Sim: 8 MimicGen tasks, 500 generated demos/task, 20k fine-tune steps, 4 backbones (SmolVLA, OpenVLA, π0.5, Motus WAM); OOD = 3–5 random RoboSuite distractor meshes with random materials; success rates (trial count per sim cell not stated clearly; grounding diagnosis uses 10 ID + 10 OOD rollouts). Real: i2RT YAM arm, wrist + top cameras, 5 tasks (3 FurnitureBench assemblies, cloth folding, closet storage), 300 demos/task, π0.5 only, 50k steps, 30 rollouts per method×ID/OOD. AFP = MobileNetV3 + deformable-DETR mask predictor with CLIP-text FiLM, trained on human-annotated soft task-relevance masks (SAM2 + MatAnyone propagation). Compute not stated.
Claim: fine-tuned VLAs attend to background/distractors (shortcut learning); an auxiliary loss aligning policy attention with task-relevance masks (PCGrad-projected) improves OOD robustness at zero inference cost.
Evidence:
 - Grounding (π0.5, avg 8 tasks): Soft-IoU direct 0.170 ID / 0.159 OOD → AFP 0.934 / 0.916; EMD 4.389/4.086 → 0.035/0.038. SmolVLA Soft-IoU 0.124/0.105 → 0.795/0.763.
 - Sim success (ID→OOD, direct vs AFP), Stack3 D1: SmolVLA ID 0.90/0.93, OOD 0.52 → 0.81; π0.5 OOD 0.61 → 0.88; Motus OOD 0.72 → 0.91. Threading D1 SmolVLA OOD 0.38 → 0.69; Kitchen D1 SmolVLA OOD 0.18 → 0.51, π0.5 0.22 → 0.59. ID gains small (+0.01 to +0.11). Pattern: every direct-finetuned model loses 0.3–0.6 absolute under distractors.
 - Real (π0.5, 30 trials each, direct → AFP): Drawer ID 0.73→0.83, OOD 0.30→0.67; Lamp ID 0.57→0.67, OOD 0.20→0.53; Table ID 0.40→0.50, OOD 0.13→0.37; Cloth ID 0.67→0.73, OOD 0.47→0.57; Closet ID 0.63→0.70, OOD 0.23→0.53.
Ablations:
 - No PCGrad projection → total loss spikes/diverges after an onset (figure; projection triggered 11,152 times in 20k steps). Qualitative/figure only, no success numbers.
 - Training efficiency: AFP converges faster on long-horizon tasks (Kitchen, Coffee Prep, 3-piece) — figure only; little difference on short tasks (Square, Coffee).
 - "Ablations over mask quality" promised in abstract but no numeric mask-quality table found in text.
Failure/limitations: needs human task-relevance annotation to train AFP; fails when relevance ambiguous/occluded/out of mask-data distribution. Critical read: OOD is only distractor objects (no lighting, camera shift, novel object appearance tested); sim numbers are suspiciously smooth with no std; no baseline against simple alternatives (background masking/crop, augmentation, object-centric inputs); real ID baseline π0.5 at 300 demos is weak (0.40–0.73).
Conflicts: consistent with Spotlighting/object-centric papers that background/distractor reliance is the main OOD failure; differs from augmentation-based approaches (ReShoot, green-screen) by supervising attention instead of diversifying pixels — complementary. Shows even large pretrained VLAs (π0.5) shortcut after fine-tuning, weakening "pretraining alone gives robustness".
Relevance: our SmolVLA fine-tune breaks under distractor/scene changes — this paper directly measures SmolVLA misgrounding (Soft-IoU 0.12) in sim. The core idea (auxiliary attention/mask loss using SAM2-propagated masks of pumpkin+tray+gripper) is cheap to implement for a small ACT/DP policy on 8 GB; no inference cost, so latency unaffected. But our shifts are lighting/appearance/camera, not tested here.
Decision impact:
 - Q09 auxiliary objectives: supports an attention/mask grounding auxiliary loss (with gradient projection) — confidence M (real robot 30 trials, 5 tasks, but only π0.5, distractor OOD only).
 - Q14 robustness: supports explicit task-relevance grounding for distractor robustness; direct fine-tune loses 0.3–0.6 under distractors — M.
 - Q03 vision encoder: weakens "large pretrained VLM backbone ⇒ robust"; all 4 backbones misground after fine-tuning — M.
 - Q12 model size: ~ no size advantage for robustness: SmolVLA and π0.5 degrade similarly OOD — L.
