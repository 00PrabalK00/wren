# W4_LIFDAnchoredDiffusionfor3DAwareSceneMemo — LIFD: Anchored Diffusion for 3D-Aware Scene Memory in Robotic Manipulation (2026, arXiv 2609.19796)
Setup: frozen LoRA-adapted VGGT encoder (geometry supervision on 100k sim + 10k real frames), multi-view self-distilled scene-token teacher, GRU memory + rectified-flow (DiT) completion of scene tokens from ONE 224×224 RGB view, slot attention, small policy head (L1 + TV smoothness). Sim: LIBERO (4 suites), MetaWorld 50 tasks, 50 demos/task, 3 seeds × 50 rollouts; RoboTwin 2.0 (50 clean demos). Real: UR5e, lateral RealSense D435i RGB, 4 task families (occluded manipulation, sequential assembly, hidden-target retrieval, long relocation), only policy head adapted from 10 demos/family, 50 trials/family with variations in poses, distractors, lighting, camera extrinsics. RTX 4090.
Claim: generative (flow) completion of a 3D-aware scene memory from single RGB + history, anchored to current features, improves control under partial observability.
Evidence: LIBERO avg: Staged 91.6% vs Joint 80.5%; MetaWorld 79.8 vs 69.4; RoboTwin Easy/Hard 63.2/19.4 vs Joint 51.6/8.8 (Hard = clean-trained → randomized env: −43.8 pts, large sensitivity to domain shift). Real UR5e (10 demos, 50 trials each; OM/SA/HTR/LR/mean): BC-R3M 36/12/32/4/21.0; OpenVLA-7B 54/32/64/12/40.5; Diffusion Policy 42/20/46/16/31.0; Lift3D 48/34/48/8/34.5; LIFD 68/62/66/28/56.0. Latency (4090): 50/35/20 RF steps → 190/130/75 ms.
Ablations (LIBERO-Spatial, full 93.6%): no RF completion (FiLM-only) 30.8 (−62.8); half-blind (single-view) teacher 51.1; no CFG 65.2; no anchor 69.9; no slot attention 70.3; no memory 74.8 (−18.8). Zeroing memory at steps 10/20/40 on LIBERO-Long reduces success (figure only). Real cup-stacking occlusion mask: recovery 4 steps (full) vs 10 (no memory) vs 12 (no anchor) — single qualitative episode.
Failure/limitations: needs multi-view supervision in pretraining; heavy (VGGT + DiT iterative sampling); baseline numbers in Table I are copied from mixed sources/settings (authors acknowledge); real baselines likely not tuned; 10-demo real regime with frozen large perception. Long-horizon relocation still 28%.
Conflicts: Memory helping here (partial observability tasks designed to require it) vs copycat literature where history hurts — difference is task design (occluded/hidden targets). Our pumpkin pick-place is essentially fully observable from scene + wrist cams.
Relevance: Low. Architecture too heavy for 8 GB/low-latency goal (190 ms on 4090 for 50 steps); our task doesn't need occlusion memory. Only general takeaways: clean-demo training is brittle to randomized environments (RoboTwin Easy→Hard −43.8 pts), and pretrained geometry-aware features + frozen perception enable 10-demo adaptation.
Decision impact:
 - Q07 history/memory: memory helps only in occlusion-heavy tasks (−18.8 pts without memory on LIBERO-Spatial in this architecture) — confidence L for our fully-observable task.
 - Q04 3D: RGB-only geometry-aware (VGGT) features beat point-cloud/3D baselines adapted to single-view — confidence L (baselines adapted, not tuned).
 - Q14 robustness: clean-demo policies drop 63→19% under environment randomization (RoboTwin) — confidence M (sim, 50 tasks) → diversify demos / augment.
