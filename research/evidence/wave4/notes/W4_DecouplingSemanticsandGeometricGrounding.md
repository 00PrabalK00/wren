# W4_DecouplingSemanticsandGeometricGrounding — Decoupling Semantics and Geometric Grounding: Spatial Visual Prompts for Language-Conditioned Imitation Learning (SVP-IL) (2026, arXiv 2606.25360)
Setup: LLM parses instruction → object name (once); SAM 3 segments target in each RGB frame → binary mask; a side-CNN encodes the mask and ADDS it to an intermediate feature map of DP's ImageNet ResNet-18; language embedding also concatenated to DP global cond. Sim: RoboTwin 2.0, 9 bimanual tasks (50 demos each) + 6 custom language-conditioned multi-object tasks (100 demos each), clean vs randomized (clutter, textures, lighting) protocols; baselines DP, ACT, π0 (full FT). Real: Aloha-AgileX bimanual, ONLY head RGB cam, 2-frame history, policy at 10 Hz with interpolation to 300 Hz, 3 cluttered language tasks, 100 demos/task, 20 trials.
Claim: offloading language grounding to a frozen segmentation foundation model and injecting the mask at feature level beats end-to-end VLAs and DP in low-data language-conditioned manipulation.
Evidence:
 - RoboTwin 9 tasks, 50 demos (Table I avg): DP 42.3, ACT 45.2, π0 53.7, SVP-IL 67.8.
 - Custom language tasks, 100 demos: DP 19.3, ACT 2.8, π0 24.0, SVP-IL 39.5.
 - Real (Table IV, 20 trials; Table Setting / Desktop Cleaning / Bimanual Sorting): DP (no language input!) 20/35/30 avg 28.3; π0 30/20/45 avg 31.7; SVP-IL 75/50/55 avg 60.0. π0 qualitatively "more sensitive to shape than color", fails same-shape-different-color targets.
Ablations:
 - Mask injection (Table III): Pixel-Overlay 50.1 (base) / 20.0 (custom); Early-Concat (4-ch input) 43.4 / 22.2; feature-level addition 67.8 / 39.5; DP 42.3 / 19.3. Learnable gating < plain addition (stated, no numbers).
 - Domain randomization (Table II; train+eval randomized vs clean): DP 42.3 → 14.9 (base), 19.3 → 6.8 (custom); SVP-IL 67.8 → 24.0, 39.5 → 12.2. NOTE eval env differs between columns (randomized eval is harder), so this is not "DR hurts" cleanly — it shows 50 randomized demos are insufficient to learn clutter/lighting robustness for DP.
Failure/limitations: SAM 3 latency (not quantified) and failures on reflective/transparent/occluded objects; ACT 2.8% on custom tasks suggests poor language conditioning for ACT in their implementation; real DP baseline had no language input → real comparison inflated; single camera in real.
Conflicts: π0 full FT only modestly better than DP on language disambiguation here, consistent with reports that VLA language following degrades under small-data fine-tuning. Agrees with Seeker (W4_AttentionfromAction) that explicit spatial bottlenecks/masks help low-data policies; agrees that early-fusion extra channels break pretrained stems (cf. depth-as-4th-channel findings).
Relevance: Our future "second object with language" phase: a detector/segmenter (e.g. SAM/GroundingDINO, or a light one) producing a target mask fused at feature level into a small DP/ACT is a data-efficient way to add language target selection with 50–100 demos, rather than relying on SmolVLA's implicit grounding. SAM 3 latency on 8 GB laptop is a concern — use a lighter segmenter or segment once + track. Also masks could give lighting/background invariance, but only weakly tested.
Decision impact:
 - Q08 language conditioning: supports decoupled grounding (segmenter mask → feature-level fusion) over end-to-end language tokens for target disambiguation at 50–100 demos (real 60 vs π0 31.7) — M (real 20 trials × 3, DP baseline had no language)
 - Q13 data: 50 demos in randomized (clutter+lighting) environments give very low success for DP (14.9%) — L (sim; eval env confound)
 - Q14 robustness: explicit target mask improves clutter/distractor robustness but randomized-scene performance still low (24%) — L
 - Q03 vision encoder: adding extra input channels (early concat) to ImageNet ResNet hurts vs mid-level feature addition (43.4 vs 67.8) — L/M (sim)
