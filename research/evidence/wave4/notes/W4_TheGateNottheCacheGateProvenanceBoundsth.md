# W4_TheGateNottheCacheGateProvenanceBoundsth — The Gate, Not the Cache: Gate Provenance Bounds the Closed-Loop Reliability of Training-Free VLA Token Skipping (2026, arXiv id not in text)
Setup: Training-free visual-token skipping (KV reuse = VLA-Cache; deletion = VLA-Pruner) on 7B OpenVLA-OFT and CogACT; LIBERO 4 suites, SIMPLER 4 tasks, ~100 paired episodes/cell; H100 + RTX 4090 latency; real AgileX Piper with wrist + global RealSense D455 used for latency only (qualitative rollout, no success stats).
Claim: Token skipping fails silently when the next step's skip gate is computed from the previous sparse forward ("self-harvested"); one dense refresh pass run during chunk execution (actuation slack) restores dense-level success while keeping 18–22% lower serve latency.
Evidence: LIBERO-Object, skip 0.9: dense 1.00; self-harvested reuse 0.68, deletion 0.31; with clean gate/refresh both 0.98. SAFE-Pruner trigger fired 3 times in 3,222 encodes while success fell to 0.19. Latency p50 (H100, LIBERO): dense 61.9–64.4 ms, VLA-Cache 52.7–54.8, VLA-Pruner 54.6–57.4, ours 49.0–53.3; RTX 4090 dense 117.9–129.8 vs ours 92.3–105.2 ms. Off-path refresh p99 79.9 ms, all within 400 ms actuation window. Action-level failure detectors (mid-chunk re-query disagreement, proprio tracking error) early-window AUROC 0.45–0.65 (useless). One-step observation delay with dense compute reduced LIBERO-Spatial success by 0.08.
Ablations: provenance × mechanism crossing (above); partial-freshness gate 0.98/0.92/0.52 at skip 0.7/0.9/0.97; optical-flow gating 0.74 vs attention gate 0.94 (Spatial, 0.9).
Failure/limitations / my read: relevant only to large-VLA token-skipping acceleration; sim-only success numbers; real robot only for latency. 
Conflicts/Relevance: Low direct relevance (we plan a small model where full dense forwards are cheap). Two transferable points for Q10: (i) use the robot's execution window of the current chunk to compute the next one (standard async idea, here validated to fit within slack); (ii) a single step of observation staleness alone costs ~8 pts on LIBERO-Spatial, so async schemes must account for stale observations (e.g., RTC-style conditioning). Also: acceleration shortcuts can silently degrade closed-loop success even when per-step action error looks negligible — evaluate speedups closed-loop.
Decision impact:
 - Q10 latency/async: one-step observation delay costs 0.08 success; off-critical-path computation during chunk execution preserves success — confidence L-M (sim, 7B VLA)
 - Q10 latency: training-free token skipping gives only 18–22% speedup and risks silent collapse — weakens it as a fix for our 2 s latency — confidence M
