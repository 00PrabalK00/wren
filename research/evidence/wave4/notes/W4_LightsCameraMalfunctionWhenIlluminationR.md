# W4_LightsCameraMalfunctionWhenIlluminationR — Lights, Camera, Malfunction: When Illumination Robustness Leaves VLA Models Blind to Color (FLARE / ChromaGuard) (2026, arXiv 2607.14698)
Setup: SmolVLA (LeRobot; pretrained VLM, action expert from scratch in sim) and π0.5. Sim: LIBERO Spatial/Object/10, 200k steps, 500 episodes/suite; spotlight parameters (HSV, intensity, height, cutoff) optimized with Optuna TPE (black-box). Real: **SO-101 Arm Pro**, wrist cam + static third-person cam, programmable RGB spotlight outside FOV; color-invariant task (red ball → black bin, 50 demos, 20 trials) and color-dependent task (red vs blue identical balls by language, 240 demos, 40 trials); fine-tune lerobot/smolvla_base and pi05_base 100k steps. Augmentations: Naive-Aug = hue ±180°, sat [0,4], value [0.2,3.0], contrast [0.8,1.2], sharpness [0.5,1.5]; ChromaGuard = same but hue fixed at 0 (described as worst-case/adversarial within that space).
Claim: VLAs are broken by a single colored spotlight; broad color jitter "fixes" it by making the model color-blind; hue-preserving augmentation gives robustness without losing color semantics.
Evidence:
 - Sim SmolVLA baseline benign/random light/optimized light (Table 1): Spatial 83.0/15.4/0.0; Object 89.4/7.8/0; LIBERO-10 58.4/22.4/0.0. Naive-Aug: Spatial 79.4/77.4/78.8; Object 89.8/91.6/93.2; LIBERO-10 50.2/49.2/47.2. Max trajectory deviation up to 115.5 cm.
 - Grayscale diagnostic (Table 2): baseline RGB→gray Spatial 81.2→0, Object 89.4→10, L10 58.4→0; Naive-Aug 79.4→80.1, 89.8→90.5, 50.2→47.8 (model ignores color).
 - REAL SO-101 (Table 3; benign / attack): color-invariant — SmolVLA baseline 70/0, Naive-Aug 80/70, ChromaGuard 80/70; π0.5 baseline 75/30, Naive 75/75, CG 70/75. Color-dependent — SmolVLA baseline 77.5/27.5, Naive-Aug 47.5/40.0 (85.7% of failures wrong-color), ChromaGuard 97.5/92.5; π0.5 baseline 47.5/12.5, Naive 40.0/47.5, CG 55.0/70.0.
Ablations: augmentation type (none / full HSV jitter / hue-fixed jitter) is the ablation above; objective-function ablation in supplement (not available).
Failure/limitations: single spotlight attack type; 20–40 trials; "adversarial training" details thin (sampling vs worst-case search unclear in real); only 2 simple tasks; no camera or object shift tests. π0.5 notably poor at color discrimination with 240 demos.
Conflicts: Refines common practice (ColorJitter incl. hue, e.g. DP/ACT defaults, RoboAgent) — hue jitter is harmful when color identifies the target. Agrees with Seeker (W4_AttentionfromAction) that naive whole-image perturbation trades off task-relevant information. SmolVLA > π0.5 on color discrimination at small data here, contrary to size intuition.
Relevance: Nearly identical to our setup (SO-101, wrist + scene cam, SmolVLA fine-tune from lerobot base, 50 demos, lighting failures). Direct recipe: brightness/contrast/saturation/sharpness jitter with hue fixed at 0 — lifts SmolVLA from 0% to 70% under strong lighting change with 50 demos, and keeps color semantics (important for pumpkin orange vs. other objects and future language tasks). Baseline SmolVLA with no aug collapses to 0% under a colored spotlight — matches our observed lighting failure.
Decision impact:
 - Q05 augmentation: supports photometric augmentation with hue FIXED (sat/value/contrast/sharpness only); full hue jitter makes policy color-blind (color task 77.5→47.5) — H (real SO-101, same model family, consistent sim diagnostic)
 - Q14 robustness (lighting): SmolVLA no-aug 70→0% under spotlight; with hue-fixed aug 80→70% — M/H (real, 20 trials)
 - Q08 language/multi-object: color-conditioned target selection needs color-preserving aug; SmolVLA 97.5% with 240 demos, π0.5 only 55% — M
 - Q12 model size: SmolVLA (~450M) outperforms π0.5 on color-dependent real task (77.5 vs 47.5 baseline; 97.5 vs 55 CG) — L/M
