# W4_FoundationandSmallModelsCoordinationforV — Foundation and Small Models Coordination for Visuomotor Policy Learning (2026, arXiv 2603.07875)
Setup: Perception-policy interface: SAM3 (text prompts for robot/gripper + target; LoRA-adapted on in-distribution data only) -> "semantic repainting": L0 = gripper and target filled with fixed role colors on black background; L1 = gripper role color + target filled with Depth Anything 3 monocular depth normalized within the target mask. Downstream small Flow Matching Policy (FMP: ResNet encoder + 1D U-Net) and SmolVLA (~450M). Sim: RoboMimic Lift, ManiSkill YCB grasp in clutter, RLBench CloseGrill/ToiletSeatDown/CloseMicrowave/OpenBox; 3 seeds, 50 rollouts/seed. Real: Franka, 2 tasks (ReachX, CloseCabinet), 25 GELLO demos (20 used per run, 3 random splits), FMP predicts target joint states from current+previous frame, 20 rollouts per condition per run. Perception timing on RTX 4060 Ti: SAM3 ~15 ms/prompt (30 ms/frame for 2 prompts), DA3 ~52 ms/frame.
Claim: Replacing raw RGB with foundation-model-constructed canonical observations (role-color masks, optional target depth) gives small policies large robustness to object color, background, and clutter shifts.
Evidence:
 - RoboMimic Lift (ID 98.7 for all): object recolor RGB 62.9 / L0 89.5 / L1 89.8; tabletop recolor 18.4 / 90.7 / 91.1.
 - ManiSkill clutter: RGB ID 98.0 -> OOD 15.0; L0 96.0 -> 93.3; L1 96.0 -> 94.0.
 - RLBench tabletop color OOD mean: RGB CloseMicrowave 80.7 ID -> 9.8 OOD, OpenBox 60.0 -> 2.4; L0 OOD CloseGrill 73.5 / Toilet 81.6 / Microwave 83.6 / OpenBox 52.9; L1 81.8 / 88.6 / 90.9 / 56.9. L0 ID is lower than RGB on CloseGrill and ToiletSeatDown (exact values figure only).
 - Real (Table I, ID / OOD1 / OOD2): ReachX RGB 61.7 / 21.7 / 25.0 vs L0 88.3 / 83.3 / 81.7; CloseCabinet RGB 85.0 / 45.0 / 48.3 vs L1 81.7 / 78.3 / 75.0.
 - SmolVLA on RLBench (Table V, ID / OOD1 / OOD2): CloseGrill RGB 76/46/42, L0 70/64/66, L1 72/66/66; CloseMicrowave RGB 64/4/8, L0 70/64/60, L1 84/78/76.
Ablations:
 - Gripper in the mask (Table II): target-only 7.3 (Lift), 5.3 (CloseGrill) vs target+robot 98.7, 74.7.
 - SAM3 LoRA on ID data (Table III, ToiletSeatDown): gripper IoU pretrained 0.0 -> 98.9-99.3; object IoU 14.0-32.9 -> 99.2-99.5 (incl. OOD colors).
 - Role colors vs ARRO-style masked RGB (same masks): Lift obj-color OOD 89.5 vs 75.5; CloseMicrowave 85.3 vs 12.7.
 - L1 repainting vs S2-style (mask+depth channels + 1x1 adapter): CloseGrill ID 82.7 vs 48.7, OOD 81-82 vs 40-45; CloseMicrowave 96.7 vs 64.0 ID, 89-92 vs 59-61 OOD.
Failure/limitations: authors: trade-off — canonicalization can lower ID success (CloseGrill/ToiletSeatDown L0 < RGB; real CloseCabinet 81.7 vs 85.0); depth value task-dependent. Critical read: shifts tested are mostly COLOR changes and clutter; lighting and camera pose shifts not tested; real tasks are simple (reach, close) with only 20 demos and no grasping; SAM3 needed manual click correction for training masks; mask failures at test time not analyzed; if the target is occluded by the gripper, mask info disappears. Latency: ~30-80 ms perception overhead per frame on a 4060 Ti-class GPU.
Conflicts: Directly extends ARRO: shows that removing object texture/color (role colors) beats keeping masked RGB (89.5 vs 75.5; 85.3 vs 12.7) — ARRO kept texture and reported it can't handle lighting; role-color rendering should also neutralize lighting inside the mask (not tested). Agrees with iDP3/3D results that geometry cues help for contact tasks (CloseMicrowave L1 > L0), but here from MONOCULAR depth, not sensor depth. Consistent with "image aug alone doesn't fix shift" findings.
Relevance: Very high: our exact model (SmolVLA) collapses to 4-8% under a tabletop color change on CloseMicrowave and recovers to 76-78% with L1 input. For pumpkin->tray: prompts "robot gripper", "pumpkin", "tray" (the tray is a second target — they used robot + ONE target; placing needs tray too). SAM3 30 ms + (optional) depth 52 ms on 4060 Ti -> fits an 8 GB RTX 5060 budget if policy is small. Could use RealSense depth instead of DA3 for L1. Would directly address "different-looking pumpkin" (color removed) and background shift; camera shift not addressed. Wrist camera: not tested.
Decision impact:
 - Q14 robustness: strongly supports segmentation-based canonical observations for object-color/background/clutter shift (real OOD 21.7->83.3, 45->78.3; SmolVLA 4->78) — M/H (sim 3 seeds x 50, real 3 runs x 20, consistent across 2 backbones)
 - Q05 augmentation: canonicalization (role-color repaint) > masked RGB foreground; alternative to heavy photometric/background augmentation — M
 - Q04 depth: target-region depth adds on contact/articulated tasks (Microwave OOD 83.6->90.9, SmolVLA 60-64->76-78), negligible on Lift/grasp — M (task-dependent)
 - Q03 vision encoder: frozen foundation segmentation (SAM3 + LoRA on ID data) as perception front-end with small ResNet policy; LoRA adaptation essential (gripper IoU 0 -> 99) — M
 - Q12 model size: small FMP policy with foundation perception front-end matches/beats SmolVLA-on-RGB under shift — L/M
 - Q10 latency: SAM3 30 ms + DA3 52 ms per frame on RTX 4060 Ti — L (overhead acceptable)
