# W4_MolmoAct2ActionReasoningModelsforRealwor — MolmoAct2: Action Reasoning Models for Real-World Deployment (2026, arXiv id not in extracted text)
Setup: Molmo2-ER VLM (from Molmo2-4B; SigLIP2 ViT) pre-trained as discrete-token VLA with MolmoAct2-FAST tokenizer (1 s of 32-D actions -> BPE tokens, 2048 vocab), then post-trained with a DiT flow-matching action expert conditioned per-layer on VLM keys/values; discrete + continuous co-training. Data: 720 h bimanual YAM (34.5k demos), filtered DROID (74.6k eps), filtered community SO-100/101 (38,059 eps / 184 h from 1,222 LeRobot datasets by 377 users, TOPReward quality gate, VLM re-annotated language). Absolute joint-pose actions, chunk = 1 s (30 steps at 30 Hz for SO-100/YAM). Image aug (light geometric + color jitter + blur), camera-order randomization. Fine-tunes: 32–64 H100, 1,152–2,304 GPU-h; real-task fine-tunes 8 H100, 50K steps. MolmoAct2-Think adds adaptive 10x10 depth-token prediction (Depth-Anything-V2 + VQ-VAE) only for changed cells. Evals: 7 benchmarks; real SO-100 zero-shot 5 tasks x 15 trials (partial credit), DROID real 5 x 15, YAM 8 tasks x 50 trials, OOD robustness 4 tasks x 20 trials.
Claim: fully open 4B-class action-reasoning VLA with per-layer KV-conditioned flow expert outperforms pi0.5 out-of-the-box and after fine-tuning, including on SO-100.
Evidence:
 - Real SO-100 zero-shot (novel objects, random 3rd-person camera pose + wrist cam, 15 trials, partial credit) Fork/Stack/Tissues/Pen/Block/avg: SmolVLA 3.3/5.0/0.0/3.3/0.0/2.3; pi0-SO100/101 (authors' fine-tune on their SO data) 30.0/6.7/20.0/80.0/90.0/45.3; MolmoAct2-SO100/101 70.0/20.0/73.3/86.7/33.3/56.7.
 - Real DROID zero-shot avg: pi0.5-DROID 45.2, MolmoBot 48.4, MolmoAct2-DROID 87.1.
 - LIBERO avg: MolmoAct2 97.2, -Think 98.1, pi0.5 96.9, GR00T N1.7 97.0, pi0 94.2.
 - Real YAM fine-tune (8 tasks x 50 trials): MolmoAct2 50.1% avg, +15 over OpenVLA-OFT (runner-up).
 - OOD robustness (4 YAM tasks, 5 trials per perturbation each) Spatial/Lighting/Language/Distractor/Overall: pi0.5 15.0/33.7/26.15/33.2/27.01; Cosmos Policy 8.75/17.5/5.0/13.75/11.25; X-VLA 3.75/8.3/9.95/3.75/6.44; OpenVLA-OFT 13.75/46.25/51.25/48.3/39.89; MolmoAct2(-Think) 26.25/62.05/60.35/54.10/50.69. Spatial (out-of-distribution object placement) is the weakest axis for all models.
 - Latency (H100, horizon 10): continuous path 23.0 Hz -> 27.4 Hz with caching -> 55.8 Hz with CUDA Graphs; Think 8.0 -> 12.7 Hz; discrete-token action path 3.94x slower than continuous (14.2 Hz).
Ablations (LIBERO):
 - Backbone Molmo2 -> Molmo2-ER (discrete actions, LIBERO-Long): 77.6 -> 83.6.
 - Expert conditioning avg: hidden-state 94.0, per-head KV 94.8, per-layer KV 95.9.
 - Flow samples per chunk K=1/2/4/8: 94.15/95.05/95.15/95.90.
 - Fine-tune recipe avg: final (full FT + discrete co-train, no knowledge insulation) 97.20; no discrete co-train 96.95; with knowledge insulation 97.05; LoRA 96.25 (−2.8 on Long); action-expert-only 93.05 (clearest failure).
 - Think depth recipe: 98.10 full; w/o noise+gate 97.65; w/o mixed training 97.50.
Failure/limitations: LIBERO ablations near ceiling (differences ~1–2 pts, single run). SO-100 real eval: 15 trials/task, partial credit, pi0 baseline trained by authors; SmolVLA (the model we currently use) given zero-shot with no task fine-tune — near 0 is not a statement about fine-tuned SmolVLA. OOD robustness uses only 5 trials per perturbation per task. Model ~4B+ with huge compute; not trainable on 8 GB; inference measured on H100.
Conflicts: Absolute joint positions chosen for SO-100/YAM/DROID (consistent with ACT, contra delta-action claims); lighting robustness came from large diverse pretraining + color-jitter aug, not 3D input. Discrete (FAST) action decoding is slower and not used at deployment — consistent with pi0-FAST vs pi0 latency findings. Tuning only the action expert with frozen VLM is worst — consistent with other findings that frozen VLM features underperform for control.
Relevance: Medium. Most useful facts for us: (1) SmolVLA zero-shot on novel SO-100 setups ~2%; a large pretrained policy with SO-100 community data reached 57% zero-shot — community SO-100 data (filtered) is a usable pretraining resource; (2) camera-order randomization + random 3rd-person camera placement at test suggests pretraining diversity handles camera-pose shift; (3) CUDA-graph + KV caching of flow loop gave 2.4x speedup — directly applicable to our latency problem with any flow head; (4) absolute joint 1-s chunks at 30 Hz on SO-100. Model itself won't fit 8 GB for training; inference maybe with quantization (not reported).
Decision impact:
 - Q10 latency: CUDA Graph + caching of flow-matching loop 23 -> 55.8 Hz (2.42x); continuous flow head 3.9x faster than discrete token decoding — confidence H (engineering measurement)
 - Q01 action head: continuous flow expert > discrete FAST decoding for speed; more flow samples per chunk in training K=8 > K=1 (95.9 vs 94.15) — confidence M
 - Q02 action space: absolute joint pose with 1-s chunks for SO-100 in a large multi-embodiment model (no ablation) — confidence L
 - Q03 vision/backbone: embodied-reasoning-specialized VLM +6 on LIBERO-Long; freezing VLM (expert-only tuning) worst 93.05 — confidence M
 - Q13 data quality: filtered + VLM-relabeled community SO-100 data supports 56.7% zero-shot on novel SO-100 tasks vs SmolVLA 2.3% — confidence M
 - Q14 robustness: lighting 62% vs pi0.5 34%; OOD spatial placement worst (26%) — confidence L-M (5 trials/perturbation/task)
 - Q12 model size: 4B-class; SmolVLA-sized models fail zero-shot on novel SO-100 setups — confidence L (not fine-tuned comparison)
