# W4_DoYouNeedProprioceptiveStatesinVisuomoto — Do You Need Proprioceptive States in Visuomotor Policies? (2025, arXiv 2509.18644)
Setup: real robots: 2x8-DoF human-like dual arm, 2x7-DoF Arx5 dual arm, 26-DoF whole-body robot; 5 real tasks (Pick Pen, Pick Bottle, Put Lid, Fold Shirt, Fetch Bottle) + LIBERO. Data: 300 episodes (~5 h) per pick&place task, 10,000 episodes (~80 h) for Fold Shirt / Fetch Bottle, collected by professional teleoperators at FIXED table height (80 cm) and object positions constrained (pen holder fixed). Cameras: overhead + wrist (normal 87x58 deg FoV, or dual wide-angle 120x120 deg top+bottom of gripper). Main model pi0 (relative EEF actions, official fine-tune recipe); also ACT and Diffusion Policy. Eval: 30 trials per cell; height gen. = 60 trials at 72/90 cm; horizontal gen. = 60 trials with target shifted 5/10 cm.
Claim: Removing proprioceptive state input (with relative-EEF actions and cameras that fully see the task) massively improves spatial generalization with no in-domain loss.
Evidence:
 - Table I (Pick Pen, pi0, normal wrist cam): w/ state 30/30 in-domain, 0/30 at 72 cm, 0/30 at 90 cm; state-hack (shift state by table height) 30/30,30/30,30/30; state noise aug (+-5 cm on z) 30/30, 24/30, 11/30; w/o state 30/30, 30/30, 17/30; dual wide-angle w/o state 30/30, 30/30, 29/30.
 - Fig. 5 Pick Pen: height gen w/ state 0 -> w/o state 0.98 (dual wide); horizontal 0 -> 0.58; normal wrist w/o state height 0.87 / horizontal 0.27. Other tasks figure only (paper: avg height 0 -> 85%, horizontal 6 -> 64%).
 - Table II horizontal gen (normal wrist cam): Fold Shirt w/ state 0.183 vs w/o 0.834; Fetch Bottle 0.117 vs 0.784.
 - Table IX in-domain: identical 1.0 for pick&place tasks; Fold Shirt 1.0 vs 0.967; Fetch Bottle 0.900 vs 0.933. LIBERO avg 0.938 (state) vs 0.945 (no state).
Ablations:
 - Action space (state-free, dual wide cams, Table III): relative EEF height 0.984 / horiz 0.584; absolute EEF, relative joint, absolute joint all 0 / 0 (all 1.0 in-domain).
 - Camera coverage (Table IV, height/horiz): overhead only 0.217/0.133; +single normal wrist 0.867/0.267; dual normal 0.920/0.400; single wide 0.917/0.500; dual wide + overhead 0.983/0.583; dual wide WITHOUT overhead 1.0/1.0.
 - Overhead camera harmful under larger shifts (Table VII, w/ vs w/o overhead): table 100 cm 0 vs 1.0; raised pen holder 0.467 vs 0.867; holder moved 20 cm 0 vs 0.800.
 - Architecture (Table V, height/horiz): pi0 w/ state 0/0 vs w/o 0.984/0.584; ACT 0/0.084 vs 0.933/0.517; DP 0/0 vs 0.867/0.533.
 - Fixes for state-based (Table VIII, height gen): state-free 0.983; state noise 0.633; diverse heights data (75-84 cm, 30 eps/cm = 300 eps) 0.117; task-mixed 0; LoRA 0.
 - Data efficiency (Fig. 6, figure only, qualitative): with 50-300 episodes state-based drops sharply as data shrinks (reaches 0 at low data), state-free stays much higher.
 - Cross-embodiment (Table VI, Fold Shirt, 100 demos): 5k steps 0.333 vs 0.700; 10k 0.767 vs 0.967.
Failure/limitations: authors: vision-only policy sensitive to background change (relocating robot/table needs re-finetune); unused arm may move unexpectedly. Critical read: "spatial generalization" test is deliberately adversarial (training data at a single height / fixed holder position) — state-based fails because the data had zero spatial variation; in our setup the pumpkin/tray positions vary across demos, so the gap should be smaller. Large datasets (300 eps/task) with professional operators; pi0 3B. Relative EEF requires good IK/FK — on SO-101 (5-DoF arm + gripper, backlash) relative EEF control is less clean; they report relative JOINT fails as badly as absolute. Wide-angle dual wrist cams are custom hardware. Overhead-removal result is on one task only.
Conflicts: Contradicts near-universal practice (ACT, DP, pi0, SmolVLA all feed state). Consistent with copycat/causal-confusion literature (state/history shortcut) and with "BC for active perception" wrist-cam delta result. Disagrees with results showing wrist-only policies fail in cluttered/global-context tasks (e.g. Robomimic/DP where agentview + wrist best) — their tasks have a single target visible from wrist. Scene-camera harm aligns with viewpoint-shift fragility reports (our "moved camera" failure).
Relevance: Directly our failures (moved camera, object placement shift). Cheap experiment: train ACT/SmolVLA with state input dropped (or heavily noised) and compare on moved-tray/pumpkin positions. Our SO-101 uses absolute joint targets — per Table III that would kill spatial generalization for a state-free policy; switching to relative EEF needs IK for a 5-DoF arm (LeRobot has kinematics for SO-101). Wrist cam on SO-101 is a small normal-FoV cam; wide-angle (fisheye) wrist cam is a cheap hardware change. Also suggests trying wrist-only vs wrist+RealSense ablation for camera-shift robustness.
Decision impact:
 - Q07 observation (proprio state input): weakens feeding proprio state; supports state-free or state-noise/dropout — confidence M/H (30-60 trials/cell, 3 architectures incl. ACT/DP, but adversarial single-position training data)
 - Q02 action space: supports relative (delta) EEF over absolute EEF / relative joint / absolute joint for spatial generalization when state-free — M (one task, 30-60 trials; in-domain all equal)
 - Q11 cameras: supports wide-FoV wrist camera(s); overhead/scene cam can HURT under placement/height shift — M (one task for overhead ablation)
 - Q14 robustness: spatial generalization (object shift 5-20 cm, height) from removing state and scene cam; background change remains a weakness — M
 - Q13 data: state-free more data-efficient at 50-100 episodes (figure only); diverse-height data (300 eps) did not rescue state-based policy (0.117) — L/M
