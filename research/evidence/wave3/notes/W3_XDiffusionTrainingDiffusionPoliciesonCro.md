# W3_XDiffusionTrainingDiffusionPoliciesonCro — X-Diffusion: Training Diffusion Policies on Cross-Embodiment Human Demonstrations (2025, arXiv id not in text)
Setup: Franka Panda, 5 real tasks (close drawer, pan on plate, push plate, mug on rack, bottle upright); 5 robot demos + 100 human single-hand demos per task; 2 calibrated RGB cams; human hand -> EE pose via HaMeR triangulation; images masked to task objects with Grounded SAM2 + rendered EE keypoints; Diffusion Policy; state=EE pose+gripper, action = next EE pose (absolute); 10 rollouts per task.
Claim: treat human actions as noisy robot actions (Ambient Diffusion): a classifier finds, per human action chunk, the minimum diffusion noise level at which it is indistinguishable from robot actions; the human sample only contributes denoising loss at noise >= that level. +16% avg success over naive co-training/filtering.
Evidence: all per-task success numbers are figure-only (Fig. 4/6). Qualitative: X-Diffusion best on all 5 tasks; naive co-training (Motion Tracks, DemoDiffusion) ~no gain over robot-only DP, Point Policy co-training can be WORSE than robot-only. Avg +16% over baselines (stated).
Ablations (figure-only, qualitative): ROBOT-ONLY < NAIVE co-train < FILTERED (manually IK-replay-verified human demos; ~50% of human demos were kinematically/dynamically infeasible and discarded) < X-Diffusion. Tasks whose human demos are more robot-compatible (mug on rack) use more human data and gain more; bottle upright gains least.
Failure/limitations: 10 trials per task; 5 robot demos per task (very low regime); calibrated multi-camera setup required; no numbers in text. Visual gap handled by object segmentation masking, which itself is a strong robustness trick not ablated.
Conflicts: Supports the general finding that indiscriminate data mixing can cause negative transfer (data quality > quantity), consistent with data-curation papers. Diffusion-noise-level gating is specific to diffusion/flow heads — an argument for a generative head if we plan to mix heterogeneous data.
Relevance: Low-moderate. If we later add human-hand videos or mixed-quality teleop demos (e.g., jerky SO-101 demos), a noise-level-gated loss is a principled way to use them. For 50-100 SO-101 teleop demos, main message: bad/infeasible demos hurt; filter or down-weight.
Decision impact:
 - Q13 data quality: naive mixing of infeasible demos gives no gain or negative transfer; filtering helps; noise-gated inclusion best — L (figure-only, 10 trials/task)
 - Q01 action head: diffusion/flow heads enable noise-level gating of low-quality data (unique capability) — L
