# W3_GoalRepresentationsforInstructionFollowi — Goal Representations for Instruction Following: A Semi-Supervised Language Interface to Control (GRIF) (2023, arXiv 2307.11049)
Setup: WidowX 250, BridgeData-style toy-kitchen scenes, 5 Hz, 6-DoF continuous EE control, Gaussian policy; 7k language-labeled + 47k unlabeled trajectories from 24 environments; ResNet-18 policy; task encoders = CLIP modified to take stacked (s0, goal) image pair, contrastively aligned with CLIP text; eval: 15 unseen instructions in 3 scenes, 10 trials (A,B) / 5 trials (C) per instruction.
Claim: contrastively aligning language with the (start, goal) TRANSITION (not static goal image), initialized from CLIP, lets a policy exploit unlabeled goal-conditioned data and follow novel instructions.
Evidence: main comparison is figure-only (qualitative): GRIF best in all 3 scenes, significantly better on 8/15 tasks; LCBC (language-only BC on 7k labeled) and R3M-goal baseline 0% on all unseen instructions; LLfP and BC-Z partial. Grounding failures (wrong object, distracted by nearby object) dominate baseline failures. Top-5 text->transition retrieval accuracy with 7k/5k/3k/1k annotations: 86/81/73/52%.
Ablations (figure only, qualitative): removing contrastive alignment, removing CLIP init, or aligning language with goal image only ("No Start", the standard CLIP-style approach — fails almost completely) all cause large drops; dropping unlabeled data drops success mainly via worse manipulation skill, not grounding; frozen vs jointly trained task encoders ~ same.
Failure/limitations: authors: not suited to "how" instructions (e.g. pour slowly); grounding limited to annotated data + CLIP. Critical read: 54k-trajectory regime; numbers mostly in figures; 5-10 trials per instruction.
Conflicts: consistent with later findings (e.g. RT-1/Octo) that language-only BC with small labeled data fails to generalize to new instructions; CLIP static image-text alignment is poor for task semantics.
Relevance: low for our current single-task setup; relevant only if we add a second object with language: with ~100 demos per object, instruction generalization is not expected — use a fixed, small set of instructions (effectively task IDs); pretrained text encoder (CLIP/SigLIP) conditioning is enough for 2 tasks.
Decision impact:
 - Q08 language: language-only BC on limited labeled data fails on unseen instructions (0%); aligning language to state change + CLIP init needed for novel phrasing — L (figure-only, large-data regime; not about our 2-task case).
