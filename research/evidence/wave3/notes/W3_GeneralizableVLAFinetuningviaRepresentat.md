# W3_GeneralizableVLAFinetuningviaRepresentat — Generalizable VLA Finetuning via Representation Anchoring and Language-Action Alignment (Anchor-Align) (2026, arXiv 2607.13429)
Setup: VLA-Adapter (Prismatic-Qwen2.5-0.5B, LoRA r=64, DINOv2+SigLIP features concatenated per patch, 2 images -> 512 patches, bridge-attention L1 regression head, 7-DoF delta EE chunks) and StarVLA (Qwen2.5-VL 3B + GR00T flow-matching DiT). Sim: LIBERO-PRO (rephrase / object swap / position swap), LIBERO-Plus (7 perturbation axes incl. camera view, lighting, background, sensor noise), CALVIN ABC->D. Real: xArm7, 4 held-out perturbation regimes, 20 rollouts/condition (demo counts in appendix, truncated).
Claim: BC finetuning erases VLM representations; adding (a) layer-wise feature distillation to a frozen VLM copy ("anchoring") and (b) an auxiliary loss predicting a motion-direction word derived from the action chunk on the same observation ("alignment") improves OOD generalization.
Evidence (Table 1, VLA-Adapter BC -> Anchor-Align): LIBERO-PRO mean 61.0 -> 71.9 (position swap 2.3 -> 22.6; OpenVLA-OFT/MolmoAct 0.0); LIBERO-Plus mean 85.1 -> 90.3; background 90.7 -> 99.6; lighting 93.2 -> 99.0; sensor noise 89.5 -> 96.9; robot init 52.6 -> 59.1; camera view 92.6 -> 96.3; object layout 93.2 -> 97.4. Frozen-backbone VLA-A: PRO 43.1, Plus 59.9 (lighting 84.9, sensor noise 36.2, camera 94.4). Co-training + Knowledge Insulation: PRO 43.8, Plus 57.1 (camera view 64.6). CALVIN avg len 4.3 -> 4.5 (5/5: 73.1 -> 77.9; OpenVLA-OFT 66.5).
 Real xArm7: VLA-Adapter mean 28.3% -> 54.2%; StarVLA 36.7% -> 60.0% (compositional layout 35->50, spatial rearrangement 30->60, clutter 45->70). Semantic "pink mug" test (StarVLA): BC picks green mug 90%, places 30%; Anchor-Align picks pink 100%, places 40%.
Ablations (Table 3, PRO/Plus means): BC 61.0/85.1; alignment only 65.9/88.6; anchoring only 68.1/87.3; both 71.9/90.3. Corrupted-label controls (shuffle 61.4/84.9, scatter 63.3/85.7) -> gain is not generic regularization. GQA accuracy: BC loses 94% within 10k steps; Anchor-Align retains 70%. Language-action agreement 16.8% -> 78.4%.
Failure/limitations: failure bins (BC -> AA): memorization 15 -> 9, grasp failure 15 -> 8, grasp-and-drop 12 -> 13, wrong object 10 -> 1, semantic 7 -> 0. Critical read: extra frozen-VLM forward per step doubles training compute/memory (a 0.5B VLM copy fits in 8 GB only tightly); real eval 20 rollouts per condition; demo count/data in truncated appendix; LIBERO-Plus camera-view gains small because baseline already high in sim.
Conflicts: Supports "fine-tune but regularize" rather than "freeze" (frozen backbone clearly worst here) — in tension with works finding frozen pretrained encoders more robust under small data; difference: here the whole VLM with LoRA, and frozen VLM features lack action-relevant spatial detail. Co-training on VQA did NOT preserve generalization (contradicts common co-training remedy). Notes the L1 regression head cannot represent multimodal actions (consistent with ACT/ActionMap).
Relevance: Directly addresses our SmolVLA fine-tune memorizing layout and failing under shift. Anchoring to a frozen copy of the pretrained VLM/encoder is a cheap, data-free regularizer applicable to SmolVLA or a small DINOv2/SigLIP policy (feature distillation to frozen encoder). The direction-word auxiliary loss is free supervision from demos.
Decision impact:
 - Q03 vision encoder: supports fine-tuning with feature-anchoring regularization over both frozen (43.1 PRO) and unregularized fine-tuning (61.0) — confidence M (sim large-scale + real 2 backbones, 20 trials).
 - Q14 robustness: anchoring+alignment improves lighting (93.2->99.0), background (90.7->99.6), position swap (2.3->22.6), real spatial rearrangement 30->60 — M.
 - Q09 auxiliary objectives: supports action-derived language-direction auxiliary loss (+4.9 PRO alone) and representation distillation (+7.1 PRO alone) — M.
 - Q08 language: plain BC binds language to training scene (90% picks trained green mug); co-training on VQA does not fix — M.
 - Q01 action head: authors avoid L1 head for multimodal test (StarVLA flow used) — L.
