# W3_VolumeDPModelingVolumetricRepresentation — VolumeDP: Modeling Volumetric Representation for Manipulation Policy Learning (2026, arXiv 2603.17720)
Setup: RGB-only diffusion policy: image features lifted into a 40x40x40 voxel grid (~1 cm voxels, task-specific workspace box) via deformable volume-image cross-attention using calibrated intrinsics/extrinsics; TokenLearner-style goal-aware selection of N=200 spatial tokens (with auxiliary BCE supervision around EE position and gripper-change locations from proprio); DiT-Block (adaLN-Zero) multi-token diffusion decoder, 100 denoising steps; inputs 256x256, 2 frames (t, t−1), 8-D proprio, DistilBERT text. Sim: LIBERO (single third-person cam, 50 demos/task, no-op/failed demos removed), ManiSkill 5 tasks (~150 scripted demos), LIBERO-Plus zero-shot; 3 seeds. Real: Galaxea R1 Lite (2x 6-DoF + gripper), head RGB (+ wrist RGB on 2 tasks), 100 teleop demos/task, 4 tasks, 20 trials per condition; baseline DP only.
Claim: lifting 2D features into an explicit 3D volume before action decoding (RGB-only, no depth sensor) fixes 2D–3D misalignment, improving success and robustness to layout, viewpoint and background shifts.
Evidence:
 - LIBERO avg (Table I): VolumeDP 88.8 vs DiT-Block Policy 74.0, DP 72.4, BC-Trans 48.4; Long 78.7 vs 57.6 / 50.5.
 - ManiSkill avg (Table II): 68.9 vs DP 49.6, DiT-Block 38.9, BC 7.0.
 - LIBERO-Plus avg (Table III): 53.0 vs DP 31.7, DiT-Block 31.1. Camera: 23.1 vs 1.6 / 1.6; Robot init 50.1 vs 32.3; Light 56.5 vs 25.0; Background 51.1 vs 19.8; Noise 44.7 vs 20.3; Layout 66.6 vs 42.2; Language 80.8 vs 77.0.
 - Real (Table V, 20 trials): ID Place Bowl 80 → 85, Microwave 60 → 75, Open Door 65 → 85, Nut on Screw 25 → 60 (avg 57.5 → 76.3). OOD: spatial (objects ~10 cm outside demo region) DP 35 → 65; camera rotated ±5° DP 0 → 40; environment (distractors, wall colour, table surface) DP 20 → 45.
Ablations (LIBERO-Spatial, Table IV): full 90.7; 2D image-feature tokens instead of volume 78.2; random voxel tokens 62.8; all voxels on coarse 10³ grid 68.4; GT-depth occupancy-based voxel selection 75.8; no auxiliary EE/gripper supervision on token weights 82.2; single-token concat decoder 76.4; conv-to-single-token 80.0.
Failure/limitations: not discussed explicitly. My read: needs camera calibration and a hand-tuned workspace box; the real "view" shift is only ±5° rotation and presumably uses the original extrinsics (so the volume is slightly misregistered) — still 40% vs DP 0%; DP baseline in real is a plain 2D DP (no strong augmentation mentioned); 100 denoising steps → slow inference (no latency reported); baselines DP/DiT-Block are weak on LIBERO-Plus camera (1.6%).
Conflicts: supports the 3D-helps-robustness line (PolarNet, GAM, DP3) but WITHOUT depth input — and learned lifting beat GT-depth occupancy selection (75.8 vs 90.7), contradicting the intuition that true depth is required. Plain 2D DP collapsing to 0% under a ±5° camera rotation is a stark data point for our "slightly moved camera" failure. LIBERO-Plus camera numbers are far below GAM (83.1) — geometric pretrained backbone > scratch volumetric lifting for large viewpoint changes.
Relevance: HIGH for our camera-shift and background/lighting failures: scene RealSense is calibrated-able; volume over the tray/pumpkin workspace is small. Also cheap auxiliary supervision from proprio (EE position, gripper-change points) to focus attention — directly applicable to any token-selecting policy. Cost: 40³x32 volume + deformable attention + 100-step diffusion may be heavy; would pair with a few-step flow head.
Decision impact:
 - Q14 robustness: supports explicit 3D lifting for camera/background/lighting shifts: real ±5° camera DP 0% vs 40%; env 20 → 45; LIBERO-Plus camera 1.6 → 23.1, light 25.0 → 56.5 — confidence M (real 20 trials, sim 3 seeds).
 - Q04 3D: RGB-only volumetric lifting beats 2D tokens (90.7 vs 78.2) and even GT-depth occupancy selection (75.8) — depth sensor not strictly necessary — confidence M.
 - Q09 auxiliary: proprio-derived attention supervision (EE + gripper-change regions) 82.2 → 90.7 — confidence L-M.
 - Q11 cameras: plain 2D policies are extremely viewpoint-fragile (±5° → 0%) — keep scene camera fixed/marked or use 3D/geometric features + camera aug — confidence M.
