# W3_LearningGeneralizableManipulationPolicie — Learning Generalizable Manipulation Policies with Object-Centric 3D Representations (GROOT) (2023, arXiv 2310.14386, CoRL 2023)
Setup: Sim: 3 LIBERO tasks, 50 demos each, 20 eval episodes x 3 seeds, +an eye-in-hand depth camera clipped to gripper range. Real: Franka, OSC EEF control at 20 Hz, one RealSense D435i workspace camera (NO wrist cam), 5 tasks (pick-place cup, stamp paper, take mug, mug on coaster, roll stamp), 50 SpaceMouse demos each; eval Canonical 10, Camera-Shift 10, Background-Change 30 (table colors, LIGHTING, distractors), New-Object 3 per object. Model: one-frame scribble mask → XMem video object segmentation → back-project task-object masks with depth to point clouds in robot-base frame (known extrinsics) → Point-MAE clusters + PointNet++ → random masking (0.6 sim / 0.75 real) → 4-layer transformer over H timesteps → GMM head (5 modes). New objects matched via SAM masks + DINOv2 cosine similarity. 100 epochs, bs 16.
Claim: object-centric (segmented) 3D point clouds in the robot frame + point masking give policies robust to background, camera viewpoint and new object instances from 50 single-setup demos.
Evidence (sim, Table 1, BC-RNN / VIOLA / MAE-policy / GROOT):
 - Moka pot: Canonical 56.7/61.7/73.3/80.0; Bg-Easy 11.7/77.5/56.7/63.3; Bg-Hard 0/0/31.7/63.3; Cam-Easy 0/0/45.0/81.7; Cam-Hard 0/0/26.7/61.7.
 - Frying pan: Canonical 51.7/90.0/81.7/65.0; Bg-Hard 0/6.7/52.5/58.3; Cam-Hard 0/1.7/65.0/73.3.
 - Reposition mugs: Canonical 63.3/85.0/66.7/73.3; Bg-Hard 0/48.3/6.7/83.3; Cam-Hard 0/5.0/8.3/38.3.
 - Real robot: figure only, qualitative: high success across Canonical/Camera-Shift/Background/New-Object; most failures = missing grasp by a few mm because the workspace camera lacks resolution and no wrist camera was used.
Ablations (moka pot, Fig 3, figure only, qualitative): raw RGB-D base fails all 4 generalization settings → object-only point clouds (incl. robot) fix background but not camera → removing robot points helps small camera shifts → random point masking needed for large camera shifts, at a modest cost on background. Point encoder (Table 3): PointNet++ vs DGCNN vs Point Transformer similar (Canonical 80.0/65.0/67.5; Cam-Hard 61.7/63.3/75.0).
Failure/limitations: requires calibrated extrinsics + depth + a segmentation/tracking stack (XMem, SAM, DINOv2) at inference — heavy and latency-adding; single instance per object assumed; GROOT sometimes WORSE than VIOLA in canonical (frying pan 65.0 vs 90.0) → the representation throws away information; sim camera shifts benefit from known extrinsics being updated (policy consumes base-frame points, so a moved camera is "free" only if you recalibrate).
Conflicts: agrees with CAGE that plain RGB(-D) end-to-end baselines collapse to ~0 under background/camera shift with 50 demos. Contrasts with CAGE's finding that RISE (full scene point cloud) collapsed under background change — GROOT's 3D robustness comes mainly from SEGMENTATION (object-centric crop), not depth per se; naive RGB-D base failed everything. Mirrors DP3/iDP3 claim that point clouds help camera shift when expressed in a fixed (robot) frame.
Relevance: Our RealSense gives depth, so an object-centric masked point cloud of the pumpkin + tray in the robot base frame is a viable robustness path for lighting/background/camera-move, but it needs extrinsic calibration (re-done after a camera bump), a segmenter at run time, and loses precision without a wrist camera (authors' own failure analysis). A hybrid (object point cloud from scene cam + wrist RGB for final grasp) is the obvious combination.
Decision impact:
 - Q04 3D vs RGB: supports segmented object point clouds in robot frame for background + camera shift (sim Cam-Hard 61.7 vs 0 BC-RNN; Bg-Hard 63.3 vs 0) — confidence M (sim numbers 3 seeds; real figure only)
 - Q04 3D vs RGB: weakens naive RGB-D input as a robustness fix (base RGB-D fails all shifts, figure) — confidence M
 - Q05 augmentation: supports random masking of input tokens/points for camera-shift robustness (figure; MAE-policy vs BC-RNN Cam-Hard 26.7 vs 0) — confidence L-M
 - Q11 cameras: authors attribute residual failures to lack of wrist camera for mm-precision grasps — supports adding wrist cam — confidence L (qualitative)
 - Q14 robustness: object-centric segmentation is the key lever for background/distractor shift — confidence M
 - Q01 action head: GMM head adequate at 50 demos (not ablated) — confidence L
