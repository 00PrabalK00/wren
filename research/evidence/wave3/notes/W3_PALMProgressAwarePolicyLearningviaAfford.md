# W3_PALMProgressAwarePolicyLearningviaAfford — PALM: Progress-Aware Policy Learning via Affordance Reasoning for Long-Horizon Robotic Manipulation (2025/26, arXiv id not in text)
Setup: VLA with learnable affordance queries (global object relevance, local contact, spatial placement points, dynamic motion) + diffusion transformer jointly predicting actions and a continuous within-subtask progress scalar; pretraining on DROID + BridgeV2 + EPIC-KITCHENS + RoboCerebra, fine-tuning on 942 human-annotated trajectories; sim CALVIN ABC→D (1000 rollouts), LIBERO (3 seeds × 500). Real: xArm6 + Gripper G2, 2 RealSense D455 RGB (wrist + base), 200 demos, 6-subtask sequential pick-place; 20 rollouts per setting, up to 3 attempts; baselines OpenVLA and Octo fine-tuned equally.
Claim: predicting structured future affordances and continuous progress stabilizes long-horizon execution (fewer repeats/skips/premature stops).
Evidence:
 - CALVIN ABC→D avg len 4.48 vs Seer 3.98, π0 3.92; 5-in-a-row 82.0% vs Seer 64.3%. LIBERO avg 94.5%, LIBERO-Long 91.8% vs CoT-VLA 69.0%.
 - Real avg length (6 subtasks): Random localization PALM 3.05 vs OpenVLA 0.95, Octo 0.65; Visual distraction 3.80 vs 1.60 / 0.95; Unseen lighting: first-subtask SR PALM 0.80 vs 0.55 / 0.50 (rest of row truncated in text).
Ablations (CALVIN avg len, pretrain / finetune stage): full 4.48; w/o affordance foresight 3.90 / 3.58; w/o inverse-dynamics prediction 4.17 / 3.92; w/o progress prediction 3.73 / 4.02. Affordance types added cumulatively G→L→S→D improve (figure only; L dips on LIBERO-Long). Removing any data source degrades, most for in-the-wild and human-annotated data (Table 4 values not extracted).
Failure/limitations: Critical read: large VLA (backbone not specified in extracted text), heavy annotation pipeline (SpatialVLM, RoboPoint labels); real baselines (OpenVLA, Octo) are weak single-step VLAs, not chunked/ACT/π0; 20 rollouts; ablations only in sim.
Conflicts: consistent with PSG-JEPA/LaST0 notes that auxiliary prediction of task-relevant structure (affordance, IDM, progress) beats plain BC; progress-prediction aligns with other work using progress to fix copycat/stall/repeat failures in non-Markovian long tasks.
Relevance: low-moderate. Pumpkin→tray is a single short pick-place; progress estimation matters more for later multi-step tasks. A progress scalar head is cheap and could help detect "stall"/repeat failures; affordance-point prediction (grasp point / tray placement) as an auxiliary target is plausible for a small model but unproven here.
Decision impact:
 - Q09 auxiliary objectives: affordance foresight (−0.9 avg len w/o), inverse dynamics (−0.56), progress (−0.46 to −0.75) each help on CALVIN — confidence L (sim ablations, big VLA).
 - Q14 robustness: under distractors/unseen lighting/random placement PALM ≫ OpenVLA/Octo (avg len 3.05–3.80 vs ≤1.60) — confidence L (weak baselines, 20 trials).
