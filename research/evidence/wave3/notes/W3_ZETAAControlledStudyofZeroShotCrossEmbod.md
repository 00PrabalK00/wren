# W3_ZETAAControlledStudyofZeroShotCrossEmbod — ZETA: A Controlled Study of Zero-Shot Cross-Embodiment VLA Transfer for Tabletop Manipulation (2026, arXiv 2609.02546)
Setup: pi0.5-style VLA; pretrain on 640K sim pick-and-place trajectories from up to 512 procedurally generated Franka-like embodiments with domain randomization (camera pose, lighting, background, layout, mass, friction); post-train on source robot only (40K traj/task sim; 50 demos/task real); evaluate on 7 held-out target robots in 4 shift categories (appearance APP, gripper GRP, arm ARM, full FULL). Two cameras: wrist + third-person, aligned poses. Metric: task progress %. Sim: 3 tasks x 7 embodiments x 100 rollouts x 3 runs; real: 2 tasks (open fryer, water flower) x 7 embodiments x 10 trials.
Claim: For zero-shot cross-embodiment transfer, gripper-frame (EEF-Delta) state and action representations, broad source diversity, auxiliary co-training, and even 5% target exposure all matter; strict vs pretrain-exposed zero-shot must be reported separately.
Evidence:
 - RQ1 sim (average over shifts): AbsEEF state + World-Delta action 60.3; AbsEEF + EEF-Delta 64.6; EEF-Delta state + World-Delta 73.4; EEF-Delta + EEF-Delta 75.7. Source robot (es): 87.7 / 92.6 / 87.8 / 91.5. ARM shift: 38.5 / 39.9 / 69.8 / 74.3; FULL: 33.9 / 38.6 / 58.4 / 60.4.
 - RQ1 real (Table 4, avg progress): 56.0 / 61.6 / 60.8 / 89.9; on the SOURCE robot itself: 87.5 / 90.0 / 85.0 / 100.0; FULL shift 21.3 / 16.3 / 43.1 / 81.9.
 - RQ3 auxiliary co-training (sim avg): none 75.7; language-action (EEF frame) 81.3; language-action both frames 77.7; subgoal 81.8; task-conditioned bbox 82.3 — gains concentrated on large embodiment shifts; source robot unchanged/slightly lower (91.5 → 89.1–90.5).
 - RQ4: 5% target-embodiment pretraining data: UR5eUMI 69.3 → 78.6, GoogleRobot 51.4 → 68.9; narrows representation gaps (33.9–60.4 → 66.9–71.1).
 - RQ2: 512-source > 1 source; real fixed-budget trend non-monotonic (8 sources worse than 1 on ARM/FULL) — figure only.
Ablations: as above — representation 2x2, number of source embodiments, auxiliary objectives, target exposure.
Failure/limitations: cross-embodiment focus (not our problem); non-embodiment factors deliberately held fixed (lighting, layout, camera aligned) so it says nothing about visual robustness; real 10 trials per pair; progress metric with partial credit.
Conflicts: EEF-frame delta actions best agrees with ActionSpaceStudy/EquiVLA (relative > absolute) and with UMI's relative-trajectory findings; conflicts with ACT's absolute-joint claim, but ZETA never tests joint space. The EEF-Delta *state* (no absolute pose) winning even on the source robot in real (100 vs 87.5–90) is notable: removing absolute proprioception reduces overfitting to absolute positions (consistent with "state-free"/proprio-dropout findings that proprioception causes copycat/overfitting).
Relevance: We use one embodiment (SO-101) so the cross-embodiment part is moot; but the representation finding transfers: gripper-frame relative actions + relative (or no) absolute state input, with a wrist cam, could improve robustness to camera shift/placement. Caveat: SO-101 has noisy kinematics/backlash, making EEF-frame computation from FK less accurate than on a Franka.
Decision impact:
 - Q02 action space: EEF-frame delta actions > world-frame delta; EEF-Delta state + EEF-Delta action best in real (89.9 vs 56–62 avg; 100 vs 85–90 on source robot, 20 trials) — supports relative gripper-frame actions and relative state — confidence M (real but few trials, Franka).
 - Q07 history/proprio: replacing absolute EEF state with relative state history improves transfer (sim avg 64.6 → 75.7) — weak support for de-emphasizing absolute proprioception — confidence L.
 - Q09 auxiliary objectives: bbox / subgoal / EEF-language-action co-training +5.6–6.6 avg (sim), mainly under shift — confidence L (cross-embodiment only).
 - Q14 robustness: domain-randomized pretraining (lighting/camera/background) used but not ablated — n/a.
