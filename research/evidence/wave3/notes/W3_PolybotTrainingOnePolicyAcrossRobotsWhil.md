# W3_PolybotTrainingOnePolicyAcrossRobotsWhil — Polybot: Training One Policy Across Robots While Embracing Variability (2023, arXiv 2307.03719)
Setup: WidowX 250S, Franka Panda, Sawyer; 64x64 images; policy uses front-mounted WRIST camera only (baseline uses exterior camera); shared upper-level EE delta-pose action env + shared IK, robot-specific action heads; contrastive (triplet) pretraining aligning observations with similar EE pose relative to task "fixed states". Data: 6 tasks x 3 robots x 3 backgrounds x 50 demos (60 h). Target: 5 demos of a new task variant on one robot; 10 object start positions per eval (10 trials).
Claim: aligning observations (wrist cams), actions (shared IK, per-robot heads) and representations (contrastive) enables cross-robot transfer.
Evidence (Table 1, few-shot 5 demos, S1-S5): Franka Polybot 0.9/0.8/0.9/1.0/0.9 vs naive multi-robot with exterior camera 0.4/0.3/0.3/0.0/0.0 vs single-robot 0.2/0.2/0.0/0.0/0.0; Sawyer and WidowX similar (Polybot 0.7-1.0; naive <=0.3; single <=0.3). Zero-shot (Table 2): Polybot 0.4-0.6 on new distractor/object, 0.4-0.5 on new-orientation shelf, 0 on tasks with new motions.
Ablations: without contrastive pretraining ~19% lower avg (e.g., Franka 0.8/0.5/0.7/0.6/0.7 vs 0.9/0.8/0.9/1.0/0.9 — pairing from garbled table approximate); blocking controller with shared action space fails on 6-DoF shelf / rotation tasks (0.0) but OK on translation-only pick/place.
Failure/limitations: needs shared-task data on all robots; no zero-shot for new motions. Critical read: wrist-vs-exterior camera is confounded with the multi-robot method (naive baseline differs in both camera and contrastive); 10 trials; 64x64; 5-demo regime.
Conflicts: consistent with other wrist-camera papers (wrist view is naturally invariant to arm appearance, background, and exterior camera placement); single-robot 5-demo results near 0 show few demos can't cover positions.
Relevance: For SO-101: suggests the wrist camera is the viewpoint-robust input — a policy leaning on wrist view is less affected by moving the scene RealSense; also supports co-training with other low-cost arms' data (SO-100/Koch) if action space is aligned (EE delta via shared IK) or per-robot heads are used.
Decision impact:
 - Q11 cameras: supports wrist camera as the embodiment/viewpoint-invariant observation (wrist-only transfer 0.7-1.0 vs exterior 0-0.4) — confidence L/M (confounded comparison, 10 trials).
 - Q13 data: supports cross-embodiment co-training when observation/action spaces are aligned; single-robot 5 demos ~0-0.3 — L/M.
 - Q02 action space: shared EE-delta with per-robot heads beats a single shared blocking-controller action space on 6-DoF tasks (0.9-1.0 vs 0.0) — L.
