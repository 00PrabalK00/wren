# W3_TrainOfflineTestOnlineARealRobotLearning — Train Offline, Test Online: A Real Robot Learning Benchmark (TOTO) (2023, arXiv 2306.00942)
Setup: Franka Panda, joint-position control 30 Hz (absolute joint targets; subsampling allowed), single RealSense D435 RGB(-D); 2 tasks (scooping, pouring) with reward = grams transferred; dataset 2,898 trajectories (~1000–2000/task: teleop via VR, noisy BC rollouts, noisy replay; lighting varies with time of day). Eval: 2 unseen containers + 1 unseen material, 3 train + 3 unseen locations, 3 seeds → 18 trials each for train/test locations. Frozen pretrained encoders + BC (quasi open-loop: predict 50-step action sequence, execute all 50).
Claim: shared-hardware benchmark; initial finding: in-domain self-supervised representations beat generic pretrained ones; BC competitive with offline RL.
Evidence (Table II, frozen encoder + BC; scooping reward/success, pouring reward/success): MoCo in-domain 7.42 / 83.3% , 22.86 / 72.2%; BYOL in-domain 4.39 / 72.2%, 20.22 / 66.6%; MoCo generic (ImageNet) 2.11 / 33.3%, 14.89 / 55.5%; ResNet50 ImageNet supervised 2.83 / 47.2%, 18.86 / 50.0%; R3M 2.97 / 44.4%, 6.94 / 33.3%. CLIP and MoCo layer-3 "performed less well" in a preliminary analysis (no numbers). Policy learning (Table III): BC+MoCo 83.3% / 72.2%; VINN 63.9 / 47.2; IQL 47.2 / 38.9; DT 27.8 / 0.0.
Ablations:
 - Dataset size (BC scooping, sorted by reward): top 5% 38.9% → 25% 72.2% → 50% 77.8% → all successes (~70%) 83.3% → 100% incl. failures 72.2% (reward 8.06 → 5.00). Filtering failed demos helps plain BC; diminishing returns after ~50%.
 - Chunking: 50-step quasi-open-loop chunks beat both closed-loop per-step and full open-loop (stated, no numbers): "closed-loop struggles without history" (scooping is non-Markovian: spoon above bowl before and after).
 - Overtraining: 2000-epoch checkpoint shows significant drop in real reward and higher validation action MSE (figure only, qualitative) — offline val MSE tracked real reward on 4 checkpoints.
 - Train vs unseen locations: figure only, qualitative: modest degradation; VINN degrades most (nearest neighbour).
Failure/limitations: authors: manual reset/reward; only 2 tasks. My read: all encoders FROZEN (no fine-tuning comparison); in-domain encoders were trained on ~2.9k trajectories of the same scene — not our regime of 50–100 demos; 18 trials per cell, one seed variance; lighting variation is incidental, not controlled.
Conflicts: agrees with "in-domain > generic frozen features" (e.g., Hansen et al. / Dasari "An unbiased look at datasets for visuo-motor pretraining"), disagrees with R3M's own claim of superiority (R3M worst on pouring, 33.3%). Agrees with ACT/DP that action chunking beats per-step closed-loop, and with work showing temporal non-Markovianity (pauses, repeated states) is handled by chunking.
Relevance: moderate. Same absolute-joint-target control paradigm as SO-101; single RealSense scene camera. Useful: (1) don't trust generic frozen features (R3M, ImageNet) — fine-tune or use in-domain adaptation; (2) remove failed/low-quality demos from BC data; (3) watch for overfitting with long training — offline action-MSE on held-out demos is a reasonable checkpoint selector.
Decision impact:
 - Q03 vision encoder: weakens frozen generic encoders (R3M 33–44%, ImageNet ResNet50 47–50%) vs in-domain SSL (72–83%) — confidence M (real, but frozen-only and large in-domain dataset).
 - Q13 data quality: supports filtering failed demos (83.3% successes-only vs 72.2% all) — confidence M.
 - Q06 chunking: supports chunked execution (50 steps @30 Hz ≈1.7 s) over per-step closed-loop for non-Markovian tasks — confidence L (no numbers).
 - Q02 action space: absolute joint targets work at 30 Hz on a PD-controlled arm — confidence L (no comparison).
