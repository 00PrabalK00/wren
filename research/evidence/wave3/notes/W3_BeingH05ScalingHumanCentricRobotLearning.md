# W3_BeingH05ScalingHumanCentricRobotLearning — Being-H0.5: Scaling Human-Centric Robot Learning for Cross-Embodiment Generalization (2026, arXiv 2601.12993)
Setup: Large VLA initialized from InternVL-3.5 (Mixture-of-Transformers: understanding expert + flow/rectified-flow action expert, "Mixture of Flow"), pretrained on UniHand-2.0 (35k h: human hand videos with MANO retargeting + ~14k h robot data incl. SO100-community). Unified delta action space. Real: 5 embodiments incl. LeRobot SO-101 (6-DoF, gripper, ONE fixed third-person D435) — SO-101 task "Clear table: put all objects into the plate"; 30–60 min demos per task; blind randomized A/B evaluation, K=20 trials per preset layout. Sim: LIBERO, RoboCasa. Deployment: rectified flow with K<10 steps, kv-cached prefix, dual-thread ring buffer, RTC-style prefix locking ("Universal Async Chunking").
Claim: Human-centric cross-embodiment pretraining + unified action space gives one checkpoint that works on 5 robots, beating pi0.5; UAC/MPG make real-time async control smooth.
Evidence:
 - Real-robot category success: figure only (Fig. 10); qualitative: specialist > generalist (close) >> pi0.5; scratch (no UniHand pretrain) specialist non-trivial but scratch generalist degrades a lot. SO-101 per-task number not extractable.
 - LIBERO 5-shot single-task (Table 6), human-centric vs native VLM init, Und+ViT frozen: 77.1 vs 51.3 avg (+25.8; Long 59.0 vs 17.4). Full fine-tune (Table 7 multi-task): 85.1 vs 84.1 (+1.0). → pretraining benefit shrinks as more parameters are trainable.
 - Frozen-layer sweep of action expert (Fig. 11/12, 20 rollouts): freezing 0–7 layers negligible (>80%), >14 layers sharp drop, fully frozen <20% → action head must be trained.
 - Masked motion token objective: MWDS Lab 0.33 vs 0.20, Wild 0.35 vs 0.28 without it.
Ablations:
 - Disabling MPG + UAC (async chunking with prefix locking) with same backbone/data: "consistent degradations", long-horizon drops sharply, bimanual oscillation/indecisive corrections (Fig. 13, figure only — no numbers).
 - Async protocol details (useful recipe): commit delay d ≥ ceil(t_inference / t_control) + margin; overestimating d is safe, underestimating breaks continuity; lock prefix during denoising; stitch only postfix; ring buffer ≥2x chunk; hold last action on underflow. Train with RTC-style random delay (prefix timesteps clean, loss on postfix only), delay distribution per embodiment.
Failure/limitations: real results figure-only; multi-billion model, 1000 GPU-h pretraining; no robustness breakdown (lighting/camera) numbers; SO-101 setup uses only a fixed D435 (no wrist cam).
Conflicts: Freeze-backbone-train-head as "optimal low-data config" conflicts with ProgVLA (frozen encoder −13.5 pts) — difference: Being-H0.5's frozen backbone was pretrained on robot/human manipulation data (so features are already action-relevant), ProgVLA's DUNE was generic. With full FT both inits converge (+1.0), consistent with "pretraining matters most when little is trainable."
Relevance: Direct SO-101 deployment evidence (low-cost arm, 10 Hz tabletop class) for an RTC-style async scheme — the exact fix for our chunk-boundary jerks under async inference. The model itself will not fit/run fast on 8 GB; the protocol is transferable to any flow/diffusion chunk policy (and a simpler inpainting-style prefix lock works even without training-time RTC).
Decision impact:
 - Q10 latency/async: RTC-style prefix locking + delay-aware training + ring buffer used across 5 robots incl. SO-101; ablation shows degradation without it (figure only) — supports prefix-conditioned async chunking — confidence M (real, many platforms, but no numbers).
 - Q03 vision encoder: when backbone is frozen, manipulation-pretrained features +25.8 pts over generic VLM init; with full FT difference ~1 pt — supports "if freezing, use robot-pretrained features; else fine-tune" — confidence M (LIBERO 5-shot).
 - Q12 model size: n/a for us (multi-B); scratch-init generalist degrades — confidence L.
 - Q01 action head: action expert must remain fully trainable (frozen expert <20%) — confidence L.
