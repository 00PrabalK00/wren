# W3_TransporterswithVisualForesightforSolvin — Transporters with Visual Foresight for Solving Unseen Rearrangement Tasks (2022, arXiv 2202.10765)
Setup: Ravens sim UR5 suction, 14 block-rearrangement tasks (6 train, 8 unseen), top-down RGB-D from 3 cams, scripted oracle demos (1/10/100/1000 per train task), 3 seeds; pick-and-place PRIMITIVES with motion planning. Real: Franka + suction, wrist-mounted RGB-D moved to a fixed pose for a top-down snapshot each step, 10 demos x 3 train tasks, 10 rollouts per task (3 train + 3 unseen).
Claim: an SE(2)-equivariant image-space visual-foresight model (cut-rotate-paste FCN) + multimodal action proposals from Goal-Conditioned Transporter + tree search generalizes zero-shot to unseen goal structures.
Evidence: Unseen tasks avg (Table I, 1/10/100/1000 demos per task): GCTN 1.3/55.4/49.0/54.2; TVF-Small 1.7/71.5/62.3/72.5; TVF-Large 2.9/78.5/71.7/85.6. Real (Table III): train tasks Row/Tower/Square GCTN 60/90/70 vs TVF 100/100/90; unseen Stair2/Rectangle/Twin Tower 40/50/0 vs 80/50/60. VF prediction L1 (10 demos, unseen, color/height): latent-dynamics baseline 0.144/0.151 vs spatial VF 0.069/0.038. Step time 0.08 s (GCTN), 0.14 s (TVF-S), 1.82 s (TVF-L) on RTX 3090.
Ablations: tree depth/clusters (Small vs Large) +7–13 points; spatially-consistent action encoding beats latent-concatenated action encoding for dynamics prediction; random translation/rotation augmentation used for VF training (not ablated in main text). Non-monotonic data scaling (100 < 10 demos), also seen in original GCTN.
Failure/limitations: deterministic foresight; fixed K proposals; needs background filtering on real robot (GCTN failed without it). Critical read: scripted unimodal-per-step demos; block worlds; primitive action space unrelated to continuous SO-101 control; 10-rollout real eval.
Conflicts: supports the general claim that single-mode argmax action selection fails where multiple valid actions exist (as in ACT/DP multimodality arguments) — here fixed by proposal + foresight scoring rather than a generative head.
Relevance: low. No bearing on continuous visuomotor policy design except: (1) multimodal proposals + selection beats single argmax, (2) equivariant/spatially-aligned representations are very data efficient for top-down pick-and-place, (3) background filtering was necessary on real hardware — a hint that clutter/background robustness is a first-order issue.
Decision impact:
 - Q01 action head: multimodal proposals + selection > single-mode argmax on unseen tasks (10 demos: 78.5 vs 55.4; real unseen twin tower 60 vs 0) — confidence L (primitive action space).
 - Q09 aux/world model: an action-conditioned foresight model used for planning adds +16–31 pts on unseen tasks — confidence L (sim blocks, planning not auxiliary loss).
