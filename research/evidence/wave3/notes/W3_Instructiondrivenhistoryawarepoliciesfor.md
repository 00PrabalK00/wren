# W3_Instructiondrivenhistoryawarepoliciesfor — Instruction-driven history-aware policies for robotic manipulations (Hiveformer) (2022, CoRL, arXiv 2209.04899)
Setup: RLBench sim, 3 RGB-D cams (128x128), KEYFRAME policy: predicts next gripper pose (position via heatmap over point cloud + quaternion + gripper) executed by a motion planner — not dense continuous control. 10 tasks x 100 demos (also 74 tasks; multi-variation Push Buttons / Tower with 10/50/100 demos per variation), 500 test episodes per task. Transformer with CLIP text tokens, cross-attention to full history of past observations/actions; aug = RGB jitter + aligned random crop; V100. Real: UR5 + RG2, 2 RealSense RGB-D side cams, push-buttons task, 10 variations x 10 scripted demos at 10 Hz, fine-tuned from sim.
Claim: jointly attending to language tokens, multi-view patches and the full observation/action history improves multi-task and instruction-generalization performance.
Evidence:
 - Ablation ladder (Table 1, single-task 10 tasks): UNet current-obs only 72.9 → +transformer 73.1 → +point cloud 77.1 → +gripper position 78.1 → +history 81.8 → +mask current obs (p=0.1) 82.3 → patch tokens instead of channel tokens 84.4 → cross-attention 88.4.
 - 74 tasks (Table 3 avg): Auto-λ 44.0, Hiveformer w/o history 60.9, one view (best of 3) 40.1, full 65.4. History matters most for Planning (78.9→81.6), Tools (46.7→53.0), Long-term (10.0→16.9); multi-view matters most for Screw/Precision/Occlusion (e.g. Multimodal 35.6 one view vs 80.9 full).
 - Multi-task 10 tasks (Table 2): Auto-λ 69.3, ours w/o instruction 64.2, ours 83.3 (single-task 88.4).
 - Multi-variation (Table 4) unseen variations, synthetic/human instructions: push buttons 10 demos/var 73.1/65.1 → 100 demos 86.4/74.0; tower 50.1/19.4 → 56.4/24.2.
 - Real (Table 5): from scratch seen 86.7 / unseen 13.3; sim-pretrained + fine-tuned 92.2 / 85.7.
Ablations (App. D, Table 7): language encoder — CLIP token sequence 86.3% on unseen push-buttons vs BERT 40.2% vs GloVe (LanCon-Learn) ~1.7%; averaged sentence embedding drops strongly (cosine 0.97 between different orders); one-hot variation id +19.4 on seen tower but no generalization to unseen; CLIP most robust to synonym-corrupted colors. Removing history hurts sequential tasks (can't tell which buttons were pressed).
Failure/limitations: authors: quadratic cost in history length; poor on >10-step tasks; synthetic instructions. Critical read: keyframe+motion-planner action space makes history cheap and copycat problems small; results don't transfer directly to dense 10–30 Hz chunked control where history often causes copycat/causal confusion. Scripted demos (unimodal). Real eval counts not given in main text.
Conflicts: history helps here (+4.5) whereas dense-control BC studies (e.g. DP's To=2 sweeps, copycat literature) find long history hurts; difference = keyframe actions (few steps, no action-copying shortcut) and tasks that genuinely need memory (which button pressed). Language token sequences > pooled embedding agrees with later VLA findings.
Relevance: moderate for later multi-object language phase: if we add a second object, use per-token text features (CLIP/SigLIP tokens) with cross-attention rather than one pooled sentence vector; history only if the task is non-Markovian (our pick-place is mostly Markovian given wrist cam + gripper state).
Decision impact:
 - Q08 language: token-level CLIP text + cross-attention; CLIP 86.3 vs BERT 40.2 on unseen instructions; w/o instruction multi-task 64.2 vs 83.3 — confidence M (sim, keyframe).
 - Q07 history: +4.5 (single-task) / +4.5 avg on 74 tasks, largest on multi-step tasks; current-obs masking p=0.1 +0.5 — confidence L-M for our dense-control case (keyframe setting).
 - Q11 cameras: multi-view vs best single view 65.4 vs 40.1 on 74 tasks, esp. occlusion/precision — confidence M (sim).
 - Q04 depth: adding point cloud +4.0 (73.1→77.1) — confidence L-M (sim, keyframe).
 - Q13 data/pretraining: sim pretraining lifts real unseen variations 13.3→85.7 — confidence L.
