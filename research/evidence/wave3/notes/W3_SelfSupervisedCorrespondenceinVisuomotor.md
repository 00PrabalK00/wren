# W3_SelfSupervisedCorrespondenceinVisuomotor — Self-Supervised Correspondence in Visuomotor Policy Learning (2019, arXiv 1909.06933)
Setup: Real Kuka IIWA + Schunk gripper, 2 fixed RealSense D415 (RGB-D, calibrated); policies consume ONE RGB stream (DD-2D) on hardware; 5 real tasks, 50–146 human demos (mouse/keyboard teleop, 6.5–27 min each); action = relative-to-current EE pose setpoint + gripper width; LSTM policy (1x100 units) trained on 5 Hz downsampled trajectories; vision = ImageNet ResNet-34 stride-8 dense-descriptor net trained self-supervised on the demo data itself (multi-view time-synced correspondence using depth + calibration), then 16 keypoints via spatial expectation -> tiny policy. Sim (Drake): 4 tasks with scripted experts, 30/50/200 demos.
Claim: pretraining the visual encoder on self-supervised dense correspondence (from the same demo data, no labels) gives near-ground-truth-state policy performance and better sample efficiency/generalization than autoencoder or end-to-end visual training.
Evidence:
 - Sim Table I (success %, Reach T / Reach T+R / Push box / Push plate): GT-3D 100/100/100/90.5; GT-2D 94.1/95.6/100/92.0; AE frozen 8.1/61.1/31.0/53.0; AE masked 16.3/10.0/73.0/67.0; AE->E2E 40.7/38.9/–/16.0; End-to-End 43.0/32.2/100/5.5; E2E with same ResNet-34 –/3.3/–/–; DD-2D (ours) 94.1/97.8/100/87.0; DD-3D (RGB-D keypoints) 100/100/–/98.0.
 - "With 30 demos our method outperforms AE and E2E with 200 demos" (Reach T+R, figure).
 - Real Table III (autonomous retries counted as success): push sugar box 6/6, with disturbances 68/70 (51 demos); flip shoe single 42/43, disturbed 35/40 (50 demos); class-general shoe flip seen shoes 38/43 (88.4%), NOVEL shoes 17/22 (77.3%) (146 demos); hang hat 42/50, disturbed 28/41 (52 demos); push-then-grab plate in clutter 21/22, disturbed 22/27 (94 demos).
Ablations:
 - Proprio-noise feedback augmentation (Table II, Reach T+R): perturb robot-state input by N(1 mm, 1 deg) while keeping the same GLOBAL setpoint label. 30 demos: DD-2D 1.1 -> 73.3, GT-2D 5.6 -> 73.3; 200 demos: DD-2D 3.4 -> 97.8, GT-2D 5.6 -> 95.6. Huge effect, independent of vision method and data amount.
 - Deeper backbone for E2E (ResNet-34) did not help closed-loop success (3.3%) though val loss dropped -> gain comes from correspondence objective, not capacity.
 - 3D keypoints (depth) > 2D: extrapolates better outside the convex hull of training object poses (Fig 4, qualitative) and Push plate 87 -> 98.
 - Fixed vs optimized descriptor set vs full end-to-end: E2E fine-tuning gave no advantage over descriptor-set optimization (stated, no numbers).
 - Push box with dynamic-feedback expert needed LSTM (history) even with GT state; static-feedback expert fine with MLP.
Failure/limitations: failures when object pose outside convex hull of training poses (2D methods); cannot handle multiple instances of same class; real results lack baselines (no real E2E comparison), small trial counts (6–70), retries count as success. Sim experts are scripted (unimodal). Old (2019) baselines — no pretrained ImageNet/DINO features baseline.
Conflicts: Agrees with later findings that object-centric/keypoint and 3D representations generalize better spatially (e.g., 3D policy papers). The proprio-noise result directly addresses the copycat/proprio-shortcut problem: with setpoint-in-global-frame labels, noising proprio forces the policy to use vision for feedback. Contrasts with modern practice (ACT/DP) that rarely noise proprio inputs.
Relevance: High for a couple of cheap tricks: (1) our SO-101 has absolute joint targets (like global setpoints) -> adding small Gaussian noise to the proprio/state input (keeping action labels) is a near-free augmentation that gave +70 pts here; for SO-101 backlash/jitter it also matches reality. (2) Our RealSense depth + wrist/scene cam could be used to self-supervise correspondence, but modern DINOv2 features give similar dense correspondence off-the-shelf. (3) 50 demos sufficed for single-object real tasks at ~90–100%.
Decision impact:
 - Q05 augmentation: supports proprio/state noise injection with unchanged global action labels — confidence M (sim, big effect, 2 methods x 2 data sizes; not real-ablated).
 - Q03 vision encoder: supports correspondence/keypoint-pretrained encoder over scratch E2E or AE at 30–200 demos — confidence M (sim; old baselines, no ImageNet-frozen feature baseline).
 - Q04 3D/depth: supports lifting keypoints to 3D with depth for spatial extrapolation (Push plate 87->98, better outside convex hull) — confidence L-M.
 - Q13 data: ~50 demos enough for 90–100% on single-instance real tasks; class-level generalization needed 146 demos and still 77% on novel instances — confidence M.
 - Q14 robustness: novel object instances 77.3% (17/22) with correspondence features — confidence L (small n).
