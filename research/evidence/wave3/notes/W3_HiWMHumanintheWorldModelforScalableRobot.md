# W3_HiWMHumanintheWorldModelforScalableRobot — Hi-WM: Human-in-the-World-Model for Scalable Robot Post-Training (2026, arXiv id not in text)
Setup: Dual-arm YAM-Ultra (6-DoF EE pose + gripper per arm, 14-D), single top-view RealSense D405, 15 Hz, leader/follower teleop. Action-conditioned latent world model trained from scratch on demos + deliberately collected failure/off-task and workspace-edge trajectories. Base policies DP and pi0 are rolled out closed-loop inside the WM; human intervenes (keyboard/leader arm/VR) near failure, with state caching, rollback and branching; corrective segments merged with real demos for post-training. 3 real tasks (Fold Towel, Push-T, Route Rope). Trial counts not stated; success percentages imply ~38/34/17 trials per task. Base dataset size not stated.
Claim: Human corrections collected inside a learned world model (not on the robot) improve real-world policy success far more than adding the policy's own successful WM rollouts.
Evidence (Table 2, real success %, DP / pi0): Fold Towel base 42.1/55.3, WM closed-loop (self-generated successes) 76.3/78.9, Hi-WM 92.1/97.4; Push-T 52.9/76.5, 64.7/79.4, 85.3/97.1; Route Rope 47.0/64.7, 70.6/82.4, 94.1/100. Avg: +37.9 pts vs base, +19.0 vs WM-CL. WM-vs-real success correlation r = 0.953. Push-T appearance/background/distractor generalization improved after post-training with WM corrections collected from varied initial images (figure only).
Ablations:
 - Edge-case data fraction 0/20/50/100% -> WM fidelity PSNR 18.50/19.82/21.15/22.53, SSIM .815/.853/.901/.942, LPIPS .152/.124/.098/.055; ~30% edge-case data already fixes most positioning errors (figure).
 - Intervention data +20% then +35% of offline dataset size -> monotonic real gains on all 3 tasks (figure only).
Failure/limitations: Requires training a task-specific world model (heavy; compute not reported) with extra failure and edge-case data; single camera; trial counts and base demo counts unreported; cost-savings claim ($45M) is extrapolated. Base-policy numbers moderate, so headroom large.
Conflicts: Consistent with DAgger/HG-DAgger-style literature that on-policy recovery corrections beat more nominal demos; WM-CL (self-generated successes) also helps (+19 pts), consistent with self-training/filtered-BC findings.
Relevance: The world model itself is out of scope for 8 GB laptop / our budget. The transferable finding: corrective/recovery data near the policy's own failure states is worth much more than equal volume of nominal data — we can do this physically with SO-101 leader arm (HG-DAgger-style interventions), ~20-35% extra data.
Decision impact:
 - Q13 data quality/recovery demos: failure-targeted corrective data (+~20-35% volume) -> +37.9 pts avg vs base and +19.0 vs same-volume self-generated successes — supports collecting intervention/recovery demos over more nominal demos — confidence M (real, 2 policies, 3 tasks, unclear trial counts)
 - Q14 robustness: corrections collected under appearance/background/distractor variation improve Push-T generalization (figure only) — L
