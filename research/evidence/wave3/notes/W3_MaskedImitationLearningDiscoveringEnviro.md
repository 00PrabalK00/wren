# W3_MaskedImitationLearningDiscoveringEnviro — Masked Imitation Learning: Discovering Environment-Invariant Modalities in Multimodal Demonstrations (2023, arXiv 2209.07682)
Setup: BC (L2, single-step) with per-modality encoders and a learned binary modality mask chosen by bi-level optimization on a validation set from a shifted environment (validation loss via learned proprio forward-dynamics rollouts). Sim: MuJoCo Reacher, Robomimic Can (can color correlated with demonstrator quality), Robomimic Square (6 low-dim modalities); real: Franka "bookshelf" reaching task with 2 RGB views (top-down view contains a spurious correlation). 3 seeds.
Claim: extra modalities cause "state over-specification" (spurious, environment-dependent inputs) and hurt generalization; selecting a subset improves OOD success.
Evidence (Table I, success %; Can / Square / Bookshelf-real): BC all modalities 22.7+-29.5 / 12.7+-5.2 / 54.17; MIL 56.0+-5.3 / 56.7+-9.8 / 95.24; MIL-aug (Square) 71.3+-4.7; OracleMask 56.0 / 59.3 / 95.24; MaskDropout 35.3 / 19.3 / 47.9; random fixed masks avg 30.7 / 18.1 / 60.9; continuous learned mask 47.3 / 2.7 / 19.8.
Ablations: on Square, masking out EEF orientation and EEF angular/linear velocities raised success (Fig. 6, qualitative); modality dropout during training does not solve it (19.3 vs 56.7); soft/continuous gating fails (2.7).
Failure/limitations: expensive (inner BC run per mask bit), order-dependent, keeps redundant modalities. Critical read: the spurious correlations are constructed by design (color <-> demonstrator; book pairing); real task is a 3-way reach with ~? demos; single-step low-capacity BC; old (2022).
Conflicts: Consistent with Robomimic finding that adding joint/EEF velocity proprio hurts, and with copycat/causal-confusion literature (Q07) — more inputs can reduce generalization. Contrasts with modern practice of feeding full proprio + multiple views to large policies; those rely on data diversity instead of input pruning.
Relevance: For SO-101: be conservative with inputs — joint positions only (no velocities), and test whether the scene RGB, wrist RGB, depth each help under our shift conditions via held-out-environment validation (e.g., demos recorded under different lighting held out for validation). Offline validation on a shifted-condition split is a cheap model-selection trick even without MIL.
Decision impact:
 - Q07 history/proprio inputs: supports minimal proprioception (drop EEF velocities/orientation extras) to avoid spurious reliance — Square 12.7 -> 56.7 — confidence L/M (sim, constructed shift).
 - Q11 cameras: an extra view can hurt when it contains spurious cues (real bookshelf 54.2 -> 95.2 after masking top view) — L (constructed correlation, simple reach task).
 - Q14 robustness: use a validation split from a shifted environment for model/modality selection — L.
