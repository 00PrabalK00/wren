# W3_ElicitingCompatibleDemonstrationsforMult — Eliciting Compatible Demonstrations for Multi-Human Imitation Learning (2022, arXiv 2210.08073, CoRL 2022)
Setup: Sim (state-based, ensemble of 5 MLPs, 7-DoF joint actions): RoboMimic Square Nut (base 50 proficient demos + 50/operator), Round Nut (base 30 + 10/operator), Hammer Placement (base 25 + 5/operator); 50 rollouts x 3 training runs. Real: Franka, kinesthetic demos, "food plating" (lift pan, tilt egg onto plate at varying location), base 15 demos from one operator + 5 per new user (n=4 users, within-subject); ensemble of 5 ImageNet ResNet-34 + MLP (MSE) policies; eval 5 plate locations x 5 rollouts (as stated in appendix; small).
Claim: adding a few demos from a new operator with a different (equally valid) strategy often HURTS a BC policy in low data; scoring state-actions by base-policy likelihood (action MSE) and novelty (ensemble std) lets you filter or, better, give live feedback so users produce compatible demos.
Evidence:
 - Naive added data (Table 1, success %): Square Nut base 38.7 -> +Op1 (same person as base) 54.3, Op2 40.3, Op3 37.3, Op4 27.3. Round Nut base 13.3 -> 26.7 / 22.0 / 17.3 / 7.3. Hammer base 24.7 -> 38.0 / 33.3 / 8.0 / 4.0. I.e., same-operator data helps, other-operator data can halve performance.
 - M-filtered: Square Nut 61.0 / 42.0 / 42.7 / 37.3; Round Nut 32.0 / 26.7 / 18.0 / 13.3; Hammer 39.7 / 32.7 / 12.0 / 4.0.
 - User studies (Table 2) base / naive / naive+filter / informed: Round Nut (n=16) 13.3 / 9.6 / 9.7 / 15.7; Hammer (n=4) 24.7 / 20.8 / 22.0 / 31.8; Real food plating (n=4) 60.0 / 30.0 / - / 85.0.
Ablations: filtering vs naive (above); informed collection beats naive for 3/4 users in within-subject Hammer study, also under HG-DAgger interventions (3/4).
Failure/limitations: authors: assumes base operator's style is "ground truth"; needs base data. Critical read: tiny data and trials (real: 4 users, ~25 rollouts per policy), large std (e.g. Hammer informed 31.8 +-16.3); MLP/MSE policies are unimodal — a multimodal head (diffusion/CVAE) might absorb conflicting styles better (authors claim multimodal methods also suffer in the sequential setting, but do not test them).
Conflicts: consistent with RoboMimic finding (single proficient operator > larger mixed-quality dataset) and with ACT's CVAE motivation (human demo variability). Contrasts with "diversity helps" results (Decomposing gap, data scaling) — the distinction is diversity of ENVIRONMENT/objects (helps) vs inconsistent STRATEGY for the same state (hurts in low data with unimodal heads).
Relevance: directly applicable to our 50-100 SO-101 teleop demos: one operator, one consistent strategy (same approach direction, grasp, drop height) per state; if multiple people collect, show them reference demos. Cheap check: ensemble-MSE of a trained policy on new demos flags inconsistent episodes to drop.
Decision impact:
 - Q13 data quality: supports consistent single-strategy demos; 5 incompatible demos can halve success (Hammer 24.7 -> 4.0; real 60 -> 30) while informed demos raise it (real 60 -> 85) — M (consistent sim+real direction, but small n).
 - Q01 action head: multimodal/inconsistent demos hurt MSE-regression MLP policies — indirectly supports multimodal heads or strict demo consistency — L.
