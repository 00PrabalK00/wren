# W3_PredVLAPredictiveSensorimotorModelingfor — PredVLA: Predictive Sensorimotor Modeling for Sub-Million-Parameter Robot Manipulation (2026, arXiv 2608.26673)
Setup: SIM ONLY, LIBERO Spatial/Goal/Object/Long (10 tasks each, 50 demos/task official), agentview + wrist cam, each through FROZEN ImageNet ResNet18 -> fixed PCA 512->96 per cam; language MiniLM -> PCA 64; proprio 9-D; action 7-D EE command via 5-component GMM head. Trainable controller 0.68M params (hierarchical multi-timescale PV-RNN, tau=(16,8,5,2)). One model per suite. 30k steps, bs 32. Online "error regression": 10 Adam iterations on latent vars over a 40-step window each control step; 46 ms/step (21.6 Hz) on RTX 5090. Eval 50 rollouts/task x 14 seeds (main); ablations 20/task x 7 seeds.
Claim: predicting sensory features (vision+proprio) and letting observations update latent state only through prediction error is a far better inductive bias than direct obs->action at <1M params.
Evidence (same frozen front end, same demos, same GMM head; Table 3/4, 4-suite mean): PredVLA 75.35 (Spatial 83.2, Goal 88.4, Object 89.2, Long 40.6) vs param-matched BC-Transformer 19.73, BC-LSTM 10.26, BC-TF chunk 8 (+ACT temporal ensembling) 16.70, chunk 16 3.44. Baselines got 50k steps + 4-point LR sweep vs 30k for PredVLA.
Ablations (3 short suites, 3-suite mean; Table 5 ladder):
 - L0 intact 86.09 -> L1 no test-time error regression (pure open loop!) 77.26 (-8.8) -> L2 no latent free variables 63.92 (-13.3) -> L3 replace prediction pathway by direct obs input 11.56 (-52.4, 70% of gap) -> L4 tau=1 10.33 -> L5 LSTM 14.52 -> L6 BC-RNN 11.68.
 - L2b: adding direct visual feed to the action pathway HURTS: 63.92 -> 48.60 (Object 66.9 -> 24.7) despite more params.
 - Table 6: remove temporal hierarchy -18.7/-17.0/-29.0 (Sp/Go/Ob); remove visual->action bottleneck -24.2/-16.1/+0.0; remove efference copy -6.5/-11.8/-3.3; open-loop LONG 40.6 -> 28.0.
 - Error channels: drop visual error -3.5/-5.0/-3.0; drop proprio error -2.8/-1.4/-14.2. Corrupting 50% of visual obs: <5 pt change; corrupting 25% of proprio: Object -49.7.
 - Chunking in the BC-TF baseline: chunk 8 16.7 vs chunk 16 3.4 vs none 19.7 (with this weak front end).
Failure/limitations: sim only, single embodiment, nominal LIBERO distribution (no visual shift test), LONG only 40.6%. Critical read: open-loop (observation-free) execution scores 77% on the short suites, i.e. LIBERO short suites are largely solvable by replaying a language-conditioned trajectory prior — so this benchmark barely tests perception; visual corruption hardly matters, the model leans on proprio. Baselines use a deliberately weak frozen ResNet18+PCA-96 front end, which explains their collapse (standard DP/ACT with trainable encoders get far higher LIBERO scores). The "direct visual input hurts" finding is plausibly overfitting of a tiny net to low-dim features, not a general truth.
Conflicts: Contradicts the usual result that chunking helps small BC policies (ACT, DP) — here chunk 16 collapses; likely because frozen low-dim features + tiny model. Proprio-dominance echoes copycat/proprio-shortcut literature (policies overweight proprioception when demos have fixed initial poses).
Relevance: Low direct relevance. Our failures are visual shifts (lighting, object look, camera move); this paper provides no evidence on those and its policy mostly ignores vision. Interesting only as a latency/size data point (0.68M controller, 46 ms incl. 10 inner optimizer steps on a 5090) and as a warning that fixed-start-pose demos let policies solve tasks nearly open-loop, inflating success without visual grounding.
Decision impact:
 - Q09 auxiliary objectives: supports sensory/proprio prediction as a core objective at tiny scale — confidence L (sim, LIBERO, weak baselines).
 - Q12 model size: a sub-1M controller on frozen features can reach 75% LIBERO — confidence L (sim, not tested under shift).
 - Q07 history/memory: recurrent multi-timescale state helps within predictive model (-17 to -29 without hierarchy) but no gain in plain BC ladder — confidence L.
 - Q14 robustness: open-loop 77% on LIBERO short suites -> benchmark success does not imply visual grounding; evaluate under shift — confidence M (direct measurement).
