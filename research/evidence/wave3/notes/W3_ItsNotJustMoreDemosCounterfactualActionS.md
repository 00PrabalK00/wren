# W3_ItsNotJustMoreDemosCounterfactualActionS — It's Not Just More Demos: Counterfactual Action Sensitivity Coverage for Data-Efficient Robust Robot Imitation (2026, arXiv n/a in text; CSIRO)
Setup: SIM ONLY. ACT base policy. (a) MuJoCo bimanual cube transfer, 14-D joint actions, 50 clean demos (A50); (b) SimplerEnv WidowX cube stacking, 7-D delta-EE actions, 200 clean demos (A200). Nuisance space: 4 families (table/background appearance, lighting/shadow, distractors near target, local support e.g. cloth patch) x 4 severities + 6 combos = 22 conditions. Eval 100 episodes per condition, 3 training seeds. Repair = fine-tune nominal checkpoint 800 epochs on clean + K selected counterfactual windows (same expert actions), lambda_cf=0.5. Candidate audit ~15 min on A2000.
Claim: Measuring "action drift" (change in predicted normalized action between paired clean/nuisance frames) ranks fragile nuisance conditions offline; selecting a small, response-diverse repair set of counterfactual frames repairs robustness far more data-efficiently than random augmentation.
Evidence:
 - Nominal ACT brittleness (Table I; transfer / stack): Clean 0.96 / 0.90; Appearance 0.09 / 0.71; Lighting 0.44 / 0.57; Distractors 0.33 / 0.00; Support 0.22 / 0.41; Combo 0.39 / 0.03; nuisance mean 0.30 / 0.32; worst 0.04 / 0.00.
 - Action drift vs failure rate: Spearman rho 0.95 (stack), 0.88 (transfer).
 - Table II Cube transfer (K=20): nominal all-nuis 0.30; random 0.56; top-drift 0.74; response-diverse (ours) 0.96 (worst 0.53, clean 0.97); random K=500: 1.00.
 - Table II Cube stacking (K=30): nominal 0.32; random 0.60; factor-balanced random 0.63; top-drift 0.63; ours 0.76 (worst 0.22); random K=500: 0.89 (worst 0.75). Clean stays ~0.87–0.93 throughout.
 - Held-out nuisance instantiations (Table IV): transfer nominal 0.02 → random 0.11 → ours 0.57 → random-500 0.90; stack nominal 0.04 → random 0.42 → ours 0.48 → random-500 0.57. Held-out worst stays ~0 except random-500 (0.80 / 0.28).
Ablations:
 - Selection rule: top-drift alone < diversity-weighted selection (0.74 vs 0.96 transfer; 0.63 vs 0.76 stack).
 - Single-factor ("collect more with distractors") repair (Fig. 5, K=30): fixes the targeted family but every single-factor repair keeps worst-case 0.0 (figure only for per-cell numbers).
 - lambda_cf 0.5–0.75 balanced; larger weights degraded clean performance (catastrophic forgetting) — preliminary sweep, no table.
Failure/limitations: sim only, 2 tasks, 3 seeds, no hardware; counterfactual images are rendered by the simulator (perfectly task-preserving), which is exactly the hard part in the real world; candidate pool must contain the deployment nuisance or it cannot be repaired; held-out transfer only partial; large random budgets eventually win on held-out (the paper's real lesson: coverage matters). Drift for stochastic heads (diffusion/flow) needs multiple samples.
Conflicts: Agrees with the general finding that small from-scratch ACT/DP are extremely brittle to lighting/appearance/distractors (e.g. SeedPolicy randomized test ≤4%); also agrees that broad visual diversity (random-500) beats narrow targeted collection for held-out generalization, consistent with data-diversity papers (Data Scaling Laws, GenGap).
Relevance: Directly our failure mode (lighting, different-looking pumpkin ≈ appearance, distractors) on an ACT-style small policy with 50 demos. Practical cheap version for us: generate paired augmented frames (color jitter / background replacement / generative relighting) from our demos, measure action drift of our trained policy to find which perturbations it is sensitive to, and weight augmentation toward those. Also a cheap offline robustness metric (action drift on augmented val frames) before running robot trials.
Decision impact:
 - Q14 robustness: small ACT trained on clean 50–200 demos loses 60–70 points under task-preserving visual nuisances — supports "must train with visual diversity" — confidence M (sim, but large effect).
 - Q05 augmentation: action-preserving counterfactual image augmentation paired with original actions repairs robustness (0.30→0.96 with 20 selected windows); more random augmented data also works at larger budget — supports augmentation/generative counterfactuals — confidence M (sim renders).
 - Q13 data: diversity/coverage of nuisance modes matters more than count; narrow single-factor collection leaves worst case at 0 — supports diverse collection over more identical demos — confidence L/M.
