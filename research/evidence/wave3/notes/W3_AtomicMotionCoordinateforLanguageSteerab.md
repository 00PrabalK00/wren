# W3_AtomicMotionCoordinateforLanguageSteerab — Atomic Motion Coordinate for Language-Steerable and Force-Responsive Manipulation (AMC) (2026, arXiv n/a in text)
Setup: dual 7-DoF arms, π0.5 fine-tuned (H=50 actions at 30 Hz, RTC execution), Qwen3.5-4B high-level planner at 1 Hz, 2,375 episodes / 3.07M samples across cabinet/drawer/fruit/screwdriver/plug/vase; adds per-arm 13-atom motion codebook (text + FK supervised, vision withheld) via cross-attention residual (34.6M params) and a wrench-history force adapter that regenerates only the unexecuted RTC suffix. Offline: 7,520 counterfactual prompt interventions; real: 50 trials per task, normalized task progress.
Claim: language alone weakly steers fine-tuned VLAs (visual motor prior dominates); an explicit FK-grounded motion coordinate makes instruction changes move the end effector, and force history improves contact tasks.
Evidence: opposite-atom separation 92.5/83.1% (single/dual prompt) vs 39.1/24.0% LA4VLA-style; fruit subtask progress fine-tuned π0.5 82.7/60.5% (familiar/OOD placement) → AMC 88.9/87.8%; force: Plug/Vase 59.0/71.6 → 78.5/75.2.
Low relevance: large dual-arm VLA with force sensing and hierarchical planner, 2.4k episodes; our setup has no F/T sensor and one task. The only transferable point: in a fine-tuned VLA, changing the instruction under identical observation weakly changes motion ("high success can reflect weak language prior over visually driven routine") — relevant if we add a second object selected by language: language must have discriminative demo coverage, otherwise the policy follows the visual routine. Force-correction regenerating only the unexecuted RTC suffix is consistent with inpainting-style async chunk execution.
Decision impact:
 - Q08 language: fine-tuned π0.5 language steering weak (opposite-atom separation 39.1/24.0% for text-steering baseline; OOD progress 60.5%) — weakens reliance on language alone for object selection without contrastive demos — confidence L (different setup)
