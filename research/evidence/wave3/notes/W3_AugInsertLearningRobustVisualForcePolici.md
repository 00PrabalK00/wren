# W3_AugInsertLearningRobustVisualForcePolici — AugInsert: Learning Robust Visual-Force Policies via Data Augmentation for Object Assembly Tasks (2024/25, arXiv 2410.14968)
Setup: dual-arm peg-in-hole, starting already in contact; Perceiver IO policy; inputs 2× 84×84 wrist RGB + 32-step F/T history + EE-pose proprio; actions = EE position deltas; L2 BC. Sim (robosuite): 50 keyboard-teleop human demos, online augmentation = replay demo actions under varied conditions (6 augmentations/demo), 6 seeds, best-checkpoint selection, variation instances held out for eval. Real: 2× UR5e + wrist RealSense D405, 50 joystick demos, 20 rollouts per condition, 1 seed.
Claim: grasp-pose variation (a multisensory perturbation) is the hardest; unisensory augmentation (visual/noise) does not fix it; F/T is the most informative modality and vision the least for this task.
Evidence: canonical 0.987 → grasp-pose variation 0.087 (sim, no augmentation). Almost all other results are figure-only (qualitative): adding grasp/shape variations to training closes their gap and incidentally helps camera-pose/scene-appearance; adding visual/scene variations or sensor noise did not improve their own OOD evaluation much; more augmentations per demo mainly help continuous grasp-pose variation. Modality ablation: No-Touch worst; No-Vision ≈ full; real: No-Proprio model IMPROVED over full model on all variations (figure only, 1 seed, 20 rollouts).
Failure/limitations: task starts in contact, so vision is nearly irrelevant by design; results mostly in figures; real 1 seed; augmentation requires simulator replay (not applicable to real teleop data).
Relevance: low-moderate. Our task is non-contact pick-place with no F/T sensor, so the modality ranking does not transfer. Two transferable hints: (1) proprio input can hurt with narrow demo pose ranges (echoes AnchorVLA4D real proprio ablation); (2) physical variations (grasp pose/object pose) are not addressed by image augmentation — need demo coverage.
Decision impact:
 - Q07 history/proprio: real No-Proprio > Full on all variations (figure only, 1 seed) — weakly weakens raw proprio input in narrow-range data — confidence L
 - Q05 augmentation: visual/noise augmentation does not fix physical (grasp-pose) shifts: 0.987 → 0.087 under grasp variation without grasp coverage — supports covering physical variation in demos, image aug only for appearance — confidence L
