# TurboVLA — Real-Time VLA at 32 Hz on an RTX 4090 with <1 GB VRAM (Xie et al., HUST, 2026, arXiv 2607.27205; code H-EmbodVis/TurboVLA)
Setup: drops the LLM: DINOv3 image encoder (ViT-B for LIBERO, ViT-L for RoboTwin) + BERT text encoder, N=6 bidirectional vision–language cross-attention layers (Grounding-DINO-style, grounding-pretrained init), ACT-style transformer decoder → continuous action chunk in ONE forward pass, trained with L1 (no generative head). No embodied pretraining. LIBERO: 12-step chunks, 50 rollouts/task (2,000). RoboTwin 2.0 clean: 50-step joint chunks, 100 rollouts/task. Real: AgileX Piper, wrist + third-view RGB-D (D435), 4 tasks × 65 demos, fine-tuned from the LIBERO checkpoint 12.5k steps, 40 trials/task, vs π0.5 same data.
Evidence:
 - LIBERO (Table 1, RTX 4090 bs 1): TurboVLA 0.2B, 0.9 GB VRAM, 31.2 ms, avg 97.7 (Spatial 99.2, Object 99.8, Goal 97.4, Long 94.2). Listed lightweight VLAs: SmolVLA (2.3B variant in table) 7.1 GB / 203.1 ms; VLA-Adapter 4.3 GB / 87.3 ms; Evo-1 1.7 GB / 137.2 ms; Diffusion Policy 0.3B 1.1 GB / 924.8 ms (sic).
 - RoboTwin 2.0 (Table 2): TurboVLA 0.4B, 43.4 ms, 60.2% avg vs π0.5 3.4B 95.6 ms 57.0%; ACT 20.4 ms 29.7%; DP 794 ms 28.0%.
 - Real Piper (Fig. 4): 92.5 / 80 / 90 / 87.5% on grab roller / move card / press stapler / stack bowls, "consistently outperforming π0.5" (π0.5 numbers figure-only).
Ablations: language conditioning: w/o language LIBERO-Goal 11.6 vs semantic instruction 97.4; text encoder SigLIP-Base 85.0 / T5-Small 91.6 / BERT 94.2 (Long suite); bidirectional interaction best (97.7 avg) vs none (95.2); interaction depth N=2/4/6/8 → 95.2(approx.)/96.x/97.7/96.6.
Failure/limitations: L1 regression head (unimodal) — async continuity fixes that rely on flow inpainting don't apply directly (VLASH-style state forwarding does). Critical read: latency for baselines measured by the authors on 4090 (SmolVLA row appears to be the 2.25B variant; DP 925 ms suggests 100-step DDPM) — cross-paper latency numbers vary widely.
Conflicts: small single-pass L1 policies at 20–45 ms reach VLA-level LIBERO success — agrees with ReactVLA/EMS that narrow-distribution tasks don't need an LLM; conflicts with RTC/BID premise that multimodal generative heads are needed for smooth chunking (here no generative head at all, synchronous).
Relevance: moderate-high: an LLM-free 0.2B design (DINOv3 + tiny text encoder + ACT decoder) fits trivially in 8 GB (0.9 GB inference) and gives 30 Hz-class inference, making async machinery almost unnecessary. Language is only needed if we add the second object.
Decision impact:
 - Q10/Q12: LLM-free 0.2B VLA gives 31 ms / 0.9 GB with 97.7 LIBERO and strong real results with 65 demos/task — M (one lab; real 40 trials/task).
 - Q10: with ~30 ms inference, synchronous or simple async execution at 10–30 Hz is feasible — M.
